## 摘要
大型语言模型可以通过微调获得新能力，但持续适应往往导致灾难性遗忘。我们提出CRAFT，一个持续学习框架，通过习得对隐藏表示的低秩干预来避免更新模型权重。CRAFT分三个阶段进行：首先根据输出分布差异将每个任务路由到一组相似任务；然后使用Kullback-Leibler散度针对该组的先前状态对模型进行微调，直接控制遗忘并决定收敛；最后利用相同的KL信号将更新任务的干预合并到共享表示中。这一设计通过单一的基于KL的目标统一了路由、正则化和合并。与基于LoRA的强方法相比，在多个基准和模型规模上，CRAFT提升了整体性能并减少了遗忘，同时对任务顺序保持鲁棒。这些结果表明，在表示空间中控制适应，并以输出空间差异为指导，为大型语言模型的持续学习提供了一种可扩展且具有原则性的方法。

## Abstract
Large language models (LLMs) can acquire new capabilities through fine-tuning, but continual adaptation often leads to catastrophic forgetting. We propose CRAFT, a continual learning framework that avoids updating model weights by instead learning low-rank interventions on hidden representations. CRAFT proceeds in three stages: it first routes each task to a group of similar tasks based on output-distribution divergence; it then fine-tunes the model using a Kullback-Leibler (KL) divergence against the group's prior state, which directly controls forgetting and determines convergence; finally, it merges interventions for the updated task into the shared representation using the same KL signal. This design unifies routing, regularization, and merging through a single KL-based objective. CRAFT improves overall performance and reduces forgetting compared to strong LoRA-based approaches across multiple benchmarks and model scales, while remaining robust to task ordering. These results suggest that controlling adaptation in representation space, guided by output-space divergence, provides a scalable and principled approach to continual learning in LLMs.

## 2. 方法论：核心思想、关键技术与算法流程
**核心思想**：  
CRAFT（Continual Representation-Anchored Fine-Tuning）基于表示微调（LoReFT）构建，以**低秩正交子空间**编辑Transformer每层的隐藏状态，不修改基础模型权重。框架通过一个统一的、基于KL散度的信号，将**任务路由、正则化训练和干预合并**串联起来。

**关键技术与算法流程**：
- **双流干预**：将每个任务的干预拆分到两个提示流上：  
  - *f-stream*：前$t_{pos}$个token位置，用于编码指令，干预参数在不同任务间共享。  
  - *l-stream*：后$t_{pos}$个token位置，用于提交输出，同样共享。  
  所有干预站点构成一个共享状态$\phi_{S_k}$，按相似任务组$S_k$聚合。
- **任务路由（基于输出分布差异）**：  
  - 新任务到达时，先以固定的随机种子进行简短预热训练（$S_{wu}$步），得到预热干预$\tilde{\phi}^{(t)}$。  
  - 计算该任务在自身数据上的输出分布$\pi_{\tilde{\phi}^{(t)}}$与各组存储分布$\pi_{\phi_{S_k}}$以及基线分布$\pi_0$的对称KL距离，并做归一化：  
    $d(t,k) = \frac{D_{KG}^k}{\max\left(\min(D_K, D_{G_k}), \epsilon\right)}$  
    其中$D_K$、$D_{G_k}$、$D_{KG}^k$分别是新任务、组基线及两者之间的KL散度。  
  - 若$d(t,k^\star) \le \delta$，则任务加入最近的组；否则开辟新组。
- **正则化微调（KL锚定训练）**：  
  - 任务被分配至组$S_k$后，冻结该组当前干预状态作为锚点$\phi_{\text{anchor}}$。  
  - 用**前向KL散度**正则化新任务干预$\phi^{(t)}$的训练：  
    $\mathcal{L}_{\text{total}} = \mathcal{L}_\tau(\phi^{(t)}) + \beta \cdot \text{KL}(\pi_{\phi_{\text{anchor}}} \| \pi_{\phi^{(t)}})$  
    该KL项直接惩罚与组先前知识的偏离，被理论证明是在给定任务损失水平下最小化对先前任务遗忘的解决方案。
  - 同一KL信号还用于**驱逐判断**：若第一轮训练的平均KL超过阈值$\eta$，说明任务被错误路由，将移入新组。
- **干预合并**：训练完成后，用训练好的$\phi^{(t)}_{\text{shared}}$直接覆盖组共享状态$\phi_{S_k}$，因其已由KL约束保持在锚点附近。

理论分析表明，CRAFT的KL正则化目标等价于在LoReFT可实现策略类中最小化与锚点的KL散度，并满足任务损失约束；结合已知遗忘规律（新任务KL漂移可预测对旧任务遗忘），该设计可达到遗忘—性能帕累托边界。

## 7. 优点
- **范式创新**：率先将持续学习完全置于表示空间，通过编辑隐藏状态而非权重解决遗忘，从根本上避免了参数空间的竞争。
- **统一且简洁的框架**：用单个KL散度目标来完成路由、正则化训练和合并，无需多个独立的机制。
- **无遗忘路由器**：基于预热输出分布的路由无需可训练参数，自然随任务到来动态构建分组，且显示出语义有意义的群组。
- **实证效果突出**：低遗忘、高整体性能，且参数量显著减少，对多种规模模型和任务序列均有效。
