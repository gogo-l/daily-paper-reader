## 摘要
持续学习使神经网络能够按顺序学习任务，而不遗忘先前获得的知识。然而，神经网络会遭受灾难性遗忘，即学习新任务会降低在先前任务上的性能。我们通过Shapley神经元评估（SNV）来解决这个问题，这是一个基于合作博弈理论的原则性框架，用于量化持续学习中神经元的重要性。SNV选择性地冻结重要神经元，同时保持其他神经元的可塑性，从而在不扩展架构的情况下实现无缓冲区持续学习。在ImageNet-1k上的实验表明，SNV始终优于现有的无缓冲区方法。特别是，在类别增量学习和任务增量学习场景中，SNV分别比第二基线方法提高了+2.88%和+6.46%的准确率。

## Abstract
Continual learning enables neural networks to learn tasks sequentially without forgetting previously acquired knowledge. However, neural networks suffer from catastrophic forgetting, where learning new tasks degrades performance on earlier ones. We address this problem with Shapley Neuron Valuation (SNV), a principled framework that quantifies Neuron importance in continual learning, grounded in cooperative game theory. SNV selectively freezes important Neurons while keeping others plastic, enabling buffer-free continual learning without expanding architecture. Experiments on ImageNet-1k show that SNV consistently outperforms existing buffer-free methods. In particular, SNV improves accuracy by +2.88% in the class incremental learning and +6.46% in the task incremental learning scenarios compared to the second baseline.

*   **核心问题：灾难性遗忘**：神经网络在连续学习多个任务时，学习新任务会严重损害其在旧任务上的性能，即发生“灾难性遗忘”。
*   **研究动机与背景**：
    *   现有的持续学习方法主要分为三类：
        *   **基于正则化**的方法（如EWC, SI）：通过约束权重更新来减少对旧知识的干扰。
        *   **基于记忆重放**的方法（如iCaRL, DER++）：存储旧任务样本并在训练新任务时进行重放。
        *   **动态架构**的方法（如PNN, DyTox）：为每个新任务扩展模型容量。
    *   但这些方法各有缺陷：基于记忆的**违反隐私原则**且存储成本高；动态架构导致**模型尺寸无限制增长**；正则化方法性能不佳。
*   **核心洞察**：现代神经网络是**高度过参数化**的，其固定容量内存在大量冗余。关键在于如何可靠地识别并保护那些对特定任务最重要的神经元。
*   **本文目标**：提出一种**无缓冲区、不扩展架构**的持续学习框架，通过量化神经元重要性来选择性冻结参数，实现旧知识的稳定和新知识的可塑性。

### 2. 方法论：Shapley 神经元估值

*   **核心思想**：将神经元的贡献评估视为一个**合作博弈问题**，其中神经元是“玩家”，模型性能是“回报”。使用博弈论中满足公平性公理的**Shapley值**来量化每个神经元对任务的重要性。
*   **关键技术与流程**：
    *   **神经元定义**：将卷积网络的每个**卷积核（滤波器）** 定义为一个基本单元“神经元”。
    *   **神经元估值**：通过掩码掉部分神经元（将其输出替换为在验证集上的均值），观察模型性能变化，来计算每个神经元的边际贡献。Shapley值 $\phi_i$ 的计算公式满足效率、空贡献、对称性和线性四大公理。
    *   **重要性掩码的构建**：对于每个任务 $t$，将Shapley值最高的前 $r\%$ 的神经元标记为重要，并冻结其权重。这就是任务专属的“专家子网络”。
    *   **冻结与更新机制**：维护一个**累积二进制掩码 $B_{t-1}$** ，标记所有前序任务使用过的重要神经元。在训练新任务时，只允许梯度更新那些**未被任何旧任务冻结的神经元**的权重。
    *   **近似计算加速**：精确计算Shapley值计算量极大，因此采用三种策略进行高效近似：
        1.  **蒙特卡洛估计**：通过随机排列神经元顺序并计算平均边际贡献来无偏估计Shapley值。
        2.  **截断**：当被掩码掉的神经元过多导致模型性能低于阈值时，跳过后续计算，以节省开销。
        3.  **多臂老虎机**：优先采样当前估计值高或不确定性大的神经元，以最小的计算代价可靠地找出最重要的前 $k$ 个神经元。

### 8. 不足与局限

*   **任务后估值开销**：**最主要的局限性**。每个任务训练完成后，需要单独的阶段来计算Shapley值，这一额外阶段的时间成本会随着网络宽度和任务复杂性增加。
