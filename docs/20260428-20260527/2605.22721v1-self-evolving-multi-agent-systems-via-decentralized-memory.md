## 摘要
自进化多智能体系统（MAS）已成为大语言模型智能体从经验中持续改进的一条有前景的路径，其基础是持久化记忆。然而，现有设计几乎毫无例外地采用跨智能体共享的集中式存储库，这带来了通信和协调开销，引发了隐私问题，并破坏了智能体多样性。我们提出DecentMem，一个去中心化记忆框架，其中每个智能体维护自己的双池记忆——一个由整合的过往轨迹构成的利用池，以及一个由大语言模型生成的、针对未见语境的候选构成的探索池。两个池基于大语言模型作为评判器的阶段性反馈在线重新加权。在理论上，我们证明该设计保证了解决方案空间的全局可达性，并实现了$O(\log T)$的累积后悔值，在常数因子内匹配随机赌博机下界。在实践中，跨三个MAS框架（AutoGen、DyLAN、AgentNet）、三个Qwen3骨干（4B/8B/14B）、两个Gemma4骨干（E2B/E4B）以及涵盖数学、代码、问答和具身任务的五个基准测试，DecentMem相较于最强集中式记忆基线平均准确率提升高达23.8%，相较于无记忆基线提升高达52.5%，同时将令牌使用量减少高达49%。

## Abstract
Self-evolving multi-agent systems (MAS) have emerged as a promising route to LLM agents that continually improve from experience, with persistent memory at their foundation. However, existing designs almost exclusively adopt a centralized repository shared across agents, incurring communication and coordination overhead, raising privacy concerns, and collapsing agent diversity. We propose DecentMem, a decentralized memory framework in which each agent maintains its own dual-pool memory -- an exploitation pool of consolidated past trajectories and an exploration pool of LLM-generated candidates for unseen contexts. The two pools are reweighted online based on stage-wise feedback from an LLM-as-a-judge. Theoretically, we prove that this design guarantees global reachability of the solution space and achieves $O(\log T)$ cumulative regret, matching the stochastic bandit lower bound up to constants. In practice, across three MAS frameworks (AutoGen, DyLAN, AgentNet), three Qwen3 backbones (4B/8B/14B), two Gemma4 backbones (E2B/E4B) and five benchmarks spanning math, code, QA, and embodied tasks, DecentMem improves average accuracy by up to 23.8% over the strongest centralized memory baseline and by up to 52.5% over the no-memory baseline, while reducing token usage by up to 49%.

## 1. 论文的核心问题与整体含义

本论文聚焦于**大语言模型驱动的多智能体系统（MAS）中的记忆机制**。传统方法采用**集中式记忆**，即所有智能体共享一个全局记忆库。作者指出这一设计存在三大根本性缺陷：

- **多样性崩塌**：所有智能体从同一记忆池中检索信息，导致行为趋于同质化，丧失多角色协同的专业互补价值。
- **系统开销沉重**：集中式读写带来高额通信、同步与一致性协调成本。
- **隐私与安全风险**：全局共享使得敏感信息在智能体间无差别暴露。

论文的核心主张是：**去中心化的智能体私有记忆是更优的设计范式**。为此提出 **DecentMem**，让每个智能体维护独立的利用-探索双池记忆，并通过在线反馈动态调整检索策略，从而在维持智能体多样性的同时实现高效自进化。

## 2. 论文提出的方法论

DecentMem 的核心是**去中心化双池记忆与自适应在线路由**。

- **双池结构**：每个智能体 \(a_m\) 拥有两个私有记忆池。
  - **利用池（E-pool）**：存放经过整合的历史成功轨迹，每条记忆包含上下文原型、动作原形以及协作轨迹细节。
  - **探索池（X-pool）**：保存针对当前任务由LLM生成的候选记忆，用于打破局部最优。
- **在线路由**：智能体在决策时，根据当前权重 \(w_{\text{E-pool}}\) 和 \(w_{\text{X-pool}}\) 计算选择E-pool的概率 \(\alpha\)。若选中E-pool，则按相似度阈值检索历史记忆；若相似度不足或选中X-pool，则生成新的探索性记忆。
- **基于评判的自适应更新**：任务执行后，由外部LLM作为评判器对每个阶段从**正确性、分配质量、中间连贯性、最终整合**四个维度评分。路由器根据相邻阶段的得分变化 \(\Delta_t\) 更新权重：
  - 若使用E-pool且得分提升（\(\Delta_t=1\)），增加其权重；
  - 若使用X-pool且得分提升，则抑制E-pool权重以防止过度依赖旧经验。
  本质上形成了一种“利用成功则加强，探索成功则抑制利用”的自适应平衡机制。
- **理论建模**：将每个智能体的搜索过程建模为图上的**随机游走+启发式远距传送**。利用池对应局部转移矩阵，探索池对应全支撑的先验分布。理论证明：
  - **全局可达性**：只要探索池持续激活，每个智能体都能遍历其局部解空间的任意区域。
  - **对数后悔值**：将双池路由视为随机赌博机问题，证明累积后悔值为 \(O(\log T)\)，在阶数上达到最优下界 \(\Omega(\log T)\)。
