## 摘要
无数据持续学习（DFCIL）依靠模型反转来合成伪样本以减轻灾难性遗忘。然而，现有反转方法受限于一个简化假设：它们使用对角协方差建模特征分布，实际上忽略了定义所学表示几何结构的特征间相关性。因此，合成的样本往往缺乏保真度，限制了知识的保留。在这项工作中，我们表明建模特征依赖性对于有效的DFCIL至关重要。我们提出了REMIX，一个结构化协方差建模框架，能够进行可扩展的全协方差建模，而无需承担密集矩阵求逆和对数行列式计算的高昂成本。通过利用拉普拉斯核参数化，REMIX使用与特征维度成线性关系的内存来捕获结构化特征依赖，同时计算上仅需额外的对数因子。对这些相关性进行建模可产生更连贯的合成样本，并在标准DFCIL基准上持续提升性能。我们的结果表明，超越对角假设对于有效且可扩展的无数据持续学习至关重要。我们的代码可在 https://github.com/pkrukowski1/REMIX-Model-Inversion-via-Laplace-Kernel 获取。

## Abstract
Data-free continual learning (DFCIL) relies on model inversion to synthesize pseudo-samples and mitigate catastrophic forgetting. However, existing inversion methods are fundamentally limited by a simplifying assumption: they model feature distributions using diagonal covariance, effectively ignoring correlations that define the geometry of learned representations. As a result, synthesized samples often lack fidelity, limiting knowledge retention. In this work, we show that modeling feature dependencies is a key ingredient for effective DFCIL. We introduce REMIX, a structured covariance modeling framework that enables scalable full-covariance modeling without the prohibitive cost of dense matrix inversion and log-determinant computation. By leveraging a Laplace kernel parameterization, REMIX captures structured feature dependencies using memory that scales linearly with the feature dimensionality, while requiring only an additional logarithmic factor in computation. Modeling these correlations produces more coherent synthetic samples and consistently improves performance across standard DFCIL benchmarks. Our results demonstrate that moving beyond diagonal assumptions is essential for effective and scalable data-free continual learning. Our code is available at https://github. com/pkrukowski1/REMIX-Model-Inversion-via-Laplace-Kernel.

### 2. 论文提出的方法论
核心框架命名为**REMIX**（**Re**constructing **M**ultivariate **I**nteractions via e**X**ponential kernel），其技术要点如下：
- **Laplace 协方差模型（LCM）**  
  - 为特征维度 \(C\) 的每个通道分配可学习的标量坐标 \(a_i\)，利用拉普拉斯核 \(K_{ij}(a)=\exp(-|a_i-a_j|)\) 捕获通道间相关性。  
  - 协方差矩阵参数化为：  
    \[
    \Sigma = \text{diag}(d) + \text{diag}(w)\,K(a)\,\text{diag}(w)
    \]  
    其中 \(d = \text{softplus}(u)+\epsilon\) 提供独立方差，\(w\in\mathbb{R}^C\) 控制尺度，参数总量为 \(O(C)\)（仅需 3C 个参数），避免密集矩阵的 \(O(C^2)\) 存储。  
  - 该参数化导致精度矩阵 \(\Sigma^{-1}\) 具有**三对角结构**（由一维坐标的马尔可夫性推导），使矩阵求逆、对数行列式及似然计算可在 \(O(C\log C)\) 时间内完成。
- **高效学习与反演**  
  - **协方差拟合**：为避免直接优化似然带来的数值问题，采用 Frobenius 范数目标 \(\|\Sigma - \hat{\Sigma}\|_F^2\)，并利用前缀/后缀和技巧将二次型计算降为 \(O(C\log C)\)，无需实例化完整核矩阵。  
  - **模型反演集成**：在 PMI 框架基础上，REMIX 用 LCM 替代原有的对角协方差假设，在生成器反演时直接优化全协方差高斯负对数似然，同时配合对比特征选择（CFS）保障目标多样性，使伪样本兼具语义真实性和分布保真度。
- **持续学习流程**  
  - 每学习完一个任务，用当前数据拟合 LCM 参数，并通过加权平均动态维护跨任务的聚合协方差估计。  
  - 特征提取器和分类器训练沿用两阶段策略：关系蒸馏 + 特征匹配 → 分类头精调，损失函数中加入基于 LCM 的分布对齐项。

### 7. 优点

### 8. 不足与局限
- **结构化表达力上限**：参数化形式基于一维坐标的拉普拉斯核，可能无法捕捉任意的、非欧氏特征相关性，表达能力弱于更灵活的生成模型或完整密集协方差。
- **架构依赖**：方法依赖批归一化（BatchNorm）或 LayerNorm 的统计信息；对无规范化层的网络需要特化处理。
- **早期层适配性**：在 ViT 的前几层（未充分混合的 patch 特征），对角模型可能反而更优，需权衡何时采用全协方差。
- **继承局限**：REMIX 构建在 PMI 的反演框架之上，会继承其生成器不完美对齐、反演目标可能偏离真实分布等潜在问题。
- **任务范围**：仅验证于图像分类类增量学习，尚未扩展到回归、分割或其他持续学习场景，也未深入讨论与差分隐私等更严格隐私要求的结合。
