## 摘要
在文献中，许多持续学习算法已被提出，以解决机器学习模型中的灾难性遗忘问题（即学习新任务导致对先前学到的任务性能下降）。尽管所有持续学习方法都使用某种形式的记忆来保留过去任务的信息，但对于需要存储哪些信息以最小化灾难性遗忘的根本性理解仍不清晰。近来，人们认识到，在存在一个所有任务共同的全局最小点的强假设下，灾难性遗忘可以完全避免。然而，在实践中，任务很少具有共同的全局最小点，一定程度的遗忘是不可避免的。本文从多任务学习的视角，提出了一个针对冲突任务进行原则性和系统性持续学习的基础框架。该方法基于寻找帕累托最优解，即根据定义，在帕累托意义上对先前任务遗忘最少的解。我们针对线性和基函数回归，以及具有二次上界的一般损失函数（如逻辑回归），推导出帕累托最小遗忘的持续学习算法。对于二次问题，PMF-CL 使用内存高效的迭代更新，对于具有 d 个参数的模型，其静态内存占用为 $\mathcal{O}(d^2)$。

## Abstract
In the literature, many continual learning (CL) algorithms have been proposed to address the issue of catastrophic forgetting in ML models (i.e., learning new tasks leads to the loss of performance on previously learned tasks). Although all CL approaches use some form of memory to retain information about past tasks, a grounded understanding of what information needs to be stored to minimize catastrophic forgetting remains elusive. Recently, it has been recognized that under the strong assumption of the existence of a common global minimizer over all tasks, catastrophic forgetting can be completely avoided. However, in practice, tasks rarely have a common global minimizer, and a certain amount of forgetting is inevitable. In this paper, we propose a foundational framework for principled and systematic CL of conflicting tasks using a multi-task learning (MTL) perspective. The approach is based on finding Pareto-optimal solutions, i.e., the solutions which, by definition, minimally forget the previous tasks in the Pareto sense. We derive Pareto-minimal-forgetting CL algorithms for linear and basis-function regression, and general loss functions which have a quadratic upper bound, e.g., logistic regression. For quadratic problems, PMF-CL uses memory-efficient iterative updates with a static memory footage of $\mathcal{O}(d^2)$ for models with $d$ parameters.

### 2. 论文提出的方法论
- **核心思想**：
  - 将持续学习视为序列化的多目标优化问题，每看到一个新任务，就在存储的旧任务损失信息的基础上，求取当前所有任务损失的帕累托最优解。
  - 定义“最小充分信息（MSI）”：完全刻画一个任务损失函数所需的最紧凑信息（如线性回归中的右奇异矩阵、奇异值和目标向量）。只要保存每个任务的MSI，就能在无需原始数据的情况下恢复其损失曲面。
  - 通过线性标量化（偏好向量按样本数加权），将多目标问题转化为加权和最小化，从而得到帕累托最优的模型参数。
- **关键技术细节**：
  - **线性/基函数回归**：利用经济奇异值分解（eSVD），将损失函数表示为 $\frac{1}{2n_t} \|\tilde{V}_t^\top \theta - \tilde{y}_t\|_{\tilde{\Sigma}_t}^2$。MSI 即为 $(\tilde{V}_t, \tilde{\Sigma}_t, \tilde{y}_t)$。
  - 推导出迭代更新式 $\mathbf{A}_k \Delta\theta_k = \alpha_k^{(k)} \tilde{V}_k \tilde{\Sigma}_k^2 (\tilde{y}_k - \tilde{V}_k^\top \theta_{k-1}^\star)$，其中 $\mathbf{A}_k$ 可通过递归 $\mathbf{A}_k = \frac{N_{k-1}}{N_k}\mathbf{A}_{k-1} + \alpha_k^{(k)} \tilde{V}_k \tilde{\Sigma}_k^2 \tilde{V}_k^\top$ 更新。该过程仅需保存 $\mathcal{O}(d^2)$ 的累加矩阵，与任务数无关。
  - **二次上界（QUB）损失（如逻辑回归）**：对真实损失函数构造二次上界 $L_t^{\text{qub}}(\theta) = L_t(\theta_t^{\min}) + \frac{1}{2}(\theta - \theta_t^{\min})^\top \mathbf{H}_t (\theta - \theta_t^{\min})$。利用 Hessian 上界矩阵 $\mathbf{H}_t$ 和任务最小点 $\theta_t^{\min}$ 作为 MSI，采用类似的迭代更新式 $\mathbf{A}_k \Delta\theta_k = \alpha_k^{(k)} \mathbf{H}_k (\theta_k^{\min} - \theta_{k-1}^\star)$，并给出遗忘上界。
- **算法流程概要**：
  - 每接收一个任务 $t$，先求其局部最优解 $\theta_t^{\min}$ 及 Hessian（或 eSVD 信息）。
  - 更新累加矩阵 $\mathbf{A}_t$ 和右侧向量，求解线性方程得到参数增量 $\Delta\theta$。
  - 更新模型参数 $\theta_t^\star = \theta_{t-1}^\star + \Delta\theta$，并存储任务 $t$ 的 MSI。
