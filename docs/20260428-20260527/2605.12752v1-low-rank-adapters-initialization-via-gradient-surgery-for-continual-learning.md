## 摘要
LoRA 因其参数效率、跨任务模块化以及与重放策略的兼容性，被广泛用于大型语言模型的持续微调。然而，基于 LoRA 的持续学习仍容易受到灾难性遗忘的影响，其严重程度取决于连续任务梯度之间的交互方式：当连续任务的梯度发生冲突时，标准的适配器初始化会将更新引导到覆盖先前学习方向的子空间中。我们提出 SLICE，一种基于梯度手术的 LoRA 适配器初始化方法，用于持续学习。SLICE 累积来自当前任务和先前任务重放缓冲区的梯度，通过投影算子调和它们，并通过截断 SVD 分解结果来初始化适配器权重。我们在 TRACE 基准和 Super-NI 任务序列上评估了 SLICE，其中包括我们通过挖掘梯度最大对立的任务对构建的一组对抗性 Super-NI 序列。与 vanilla LoRA、LoRA-GA 和 LoRAM 相比，SLICE 始终实现更好的稳定性-可塑性权衡，提高了平均性能、最终性能和遗忘指标，同时在标准和对抗性持续学习序列中保持了一般性能和上下文性能。

## Abstract
LoRA is widely adopted for continual fine-tuning of Large Language Models due to its parameter efficiency, modularity across tasks, and compatibility with replay strategies. However, LoRA-based continual learning remains vulnerable to catastrophic forgetting, whose severity depends on how successive task gradients interact: when consecutive task gradients conflict, standard adapter initializations channel updates into subspaces that overwrite previously learned directions. We propose SLICE, a gradient-surgery-based initialization for LoRA adapters in continual learning. SLICE accumulates gradients from both the current task and a replay buffer of prior tasks, reconciles them through a projection operator, and decomposes the result via truncated SVD to initialize the adapter weights. We evaluate SLICE on the TRACE benchmark and sequences of Super-NI tasks, including a set of adversarial Super-NI sequences that we construct by mining task pairs with maximally opposing gradients. Compared to vanilla LoRA, LoRA-GA, and LoRAM, SLICE consistently achieves a better stability-plasticity trade-off, improving Average Performance, Final Performance and Forgetting metrics while preserving General Performance and In Context Performance across both standard and adversarial continual learning sequences.

### 1. 论文的核心问题与整体含义

- **研究动机**：大型语言模型在不断变化的非平稳任务分布中进行顺序自适应时，使用 LoRA 进行持续微调虽然参数高效，但灾难性遗忘依然严重。
- **关键问题**：标准 LoRA 适配器初始化（如随机高斯加零初始化）盲于任务之间的梯度冲突。当连续任务的梯度发生冲突（Frobenius 内积为负）时，任何仅优化当前任务的更新都会破坏先前任务的知识。初始化阶段决定了后续所有优化的子空间，而现有初始化方法（piSSA、LoRA-GA 等）都未考虑先前任务的信息，容易将适配器引向覆盖旧知识的子空间。
- **整体含义**：提出 SLICE（Gradient-Surgery-based Low-rank Initialization for Continual lEarning），利用梯度手术在初始化阶段就调和当前任务与先前任务的梯度冲突，从而为 LoRA 适配器选择一个既能对齐当前任务目标又对旧任务破坏最小的子空间，从根本上缓解灾难性遗忘。

### 2. 论文提出的方法论

- **核心思想**：在每一次新任务开始前，通过四个阶段为 LoRA 适配器提供一组冲突感知的初始权重，使初始更新方向与当前任务梯度一致且与先前任务梯度正交或非冲突。
- **关键技术细节与流程**：
  - **阶段一：梯度估计**。对当前任务数据 `D_cur` 和先前任务回放样本 `D_prev`（一次性采样，不持久回放）分别累积梯度，得到 `G_cur` 和 `G_prev`。
  - **阶段二：梯度调和**。使用投影算子 `ψ`（基于 PCGrad 的广义版本，用系数 `c ∈ [0,1]` 控制）调和 `G_cur` 和 `G_prev`，仅当两者冲突时（内积为负）才将 `G_cur` 中与 `G_prev` 冲突的分量投影掉，得到调和后的梯度 `˜G_cur`。
    - 公式：`ψ_PCGrad(G_cur, G_prev, c) = G_cur − c * min(⟨G_cur, G_prev⟩_F, 0) / ‖G_prev‖^2_F * G_prev`
  - **阶段三：低秩分解**。对 `˜G_cur` 进行截断奇异值分解，取前 `r` 个左奇异向量作为 `B` 的初始化基，取第 `(r+1)` 到 `2r` 个右奇异向量的转置作为 `A` 的初始化基（借鉴 LoRA-GA 的经验设定）。
  - **阶段四：幅度重标定**。利用 magnitude gain initialization 方法将初始适配器的方差与预训练权重的方差对齐，避免幅度放大带来的混淆效应。
  - **整合**：初始化后的适配器可直接用于标准或重放增强的训练流程，不绑定下游训练算法。

### 6. 论文的主要结论与发现

- **稳定性‑可塑性权衡显著改善**：SLICE 在所有序列上均降低了遗忘（Fgt），同时保持或提升最终性能（FP），尤其在梯度冲突严重的 NI‑Seq‑Opposite 序列上，对 Vanilla LoRA 的 FP 提升可达 22.55 点，遗忘减少超过 20 点；对 LoRAM 和 LoRA‑GA 同样有一致提升。

- **对抗性序列的必要性**：新构建的 NI‑Seq‑Opposite 能暴露标准序列不易发现的差异，SLICE 在该类序列上的优势尤为突出。
- **梯度手术仅作用于初始化阶段**，生成的适配器可与任何下游训练方法兼容。

### 7. 优点

- **新颖且针对性强的方案**：聚焦于适配器初始化这一被忽视但关键的阶段，利用梯度手术直接解决连续任务梯度冲突。
- **轻量且可组合**：只需在初始化时进行一次梯度累积和 SVD，不改变后续训练流程，可与各种持续学习策略配合使用。
- **公平的评估协议**：引入幅度重标定消除了幅度混淆，引入对抗性梯度序列 NI‑Seq‑Opposite 增强了评估的区分度。
- **详尽的实验分析**：覆盖多种序列、秩大小、α 值，并同时评估任务性能与通用能力，分析全面深入。

### 8. 不足与局限

- **计算开销**：初始化阶段需要额外的前向/反向传播和小样本梯度累积，并对每个目标矩阵进行 SVD，对于资源极度受限的场景可能不适用（相比 LoRAM 的几乎零成本初始化）。
- **通用性能代价**：SLICE 带来的 FP 和 Fgt 增益是以轻微降低 GP 和 IP 为代价的，虽可通过 α 调节，但仍存在一定的泛化能力牺牲。
- **对先验数据依赖**：需要存储一份先前任务的回放样本 `D_prev`（尽管只使用一次），在严格无记忆的设定下可能受限。
- **评估范围**：主要在 Super‑NI 和 TRACE 基准上验证，未在其他类型的持续学习基准（如视觉或强化学习）上测试；序列长度限制为 5 个任务，更长序列的效果未探明。
- **理论缺位**：对低秩分解中为何取第 (r+1) 到 2r 个奇异向量未给出理论解释，仅依经验沿用。
