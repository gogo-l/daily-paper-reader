## 摘要
利用遥感和深度学习自动绘制和分割全球采矿足迹对于监测采矿的社会环境风险和影响至关重要，但其进展因细粒度标注数据的稀缺而受到阻碍。尽管具有粗糙边界的大规模数据集广泛可用，但由于显著的域偏移，利用它们改进细粒度分割颇具挑战。为此，我们提出MineC2FNet，一个从粗到细的域增量学习框架，该框架利用丰富的粗数据来增强细粒度采矿足迹分割。MineC2FNet采用教师-学生架构，在特征和预测层面进行注意力蒸馏，选择性地从粗域传递泛化知识，同时利用有限的细粒度数据（细域）实现边界细化。我们还引入了一个经过专家验证的数据集，包含219张图像，具有精确的边界标注，涵盖多样的地理区域和矿产类型。针对包括域适应和域增量学习方法在内的最先进方法的大量实验表明，MineC2FNet在有效处理域偏移的同时实现了卓越的性能。数据集和代码公开于https://github.com/risqiutama/MineC2FNet。

## Abstract
Automatically mapping and segmenting global mining footprints using remote sensing and deep learning is critical for monitoring the socio-environmental risks and impacts of mining, yet its progress is hindered by the scarcity of fine-grained annotated data. Although large-scale datasets with coarse boundaries are widely available, leveraging them to improve fine-grained segmentation is challenging due to significant domain shift. To address this, we propose MineC2FNet, a coarse-to-fine domain incremental learning framework that exploits abundant coarse data to enhance fine-grained mining footprint segmentation. MineC2FNet adopts a teacher-student architecture with attentive distillation at both the feature and prediction levels, selectively transferring generalized knowledge from the coarse domain while enabling boundary refinement using limited fine-grained data (fine domain). We further introduce an expertly validated dataset of 219 images with precise boundary annotations across diverse geographies and commodities. Extensive experiments against state-of-the-art approaches, including domain adaptation and domain incremental learning methods, demonstrate that MineC2FNet achieves superior performance while effectively handling domain shift. The dataset and code are publicly available at https://github.com/risqiutama/MineC2FNet.

### 2. 方法论：核心思想与关键技术细节
- **总体框架（MineC2FNet）**：采用教师-学生架构，分两阶段训练。第一阶段在粗标注数据集上训练教师模型，得通用特征提取能力；第二阶段冻结教师模型，在细标注数据集上训练学生模型，并通过注意力蒸馏选择性地迁移教师知识。
- **注意力特征注入**：将教师骨干（特征提取器）的副本插入学生网络，提取粗域通用特征 \(F_{\text{coarse}}\)，与学生细域特征 \(F_{\text{fine}}\) 融合。融合过程包含四个模块：
  - **门控融合（GF）**：通过可学习的像素级门控机制动态融合两路特征。
  - **CBAM**：对融合特征施加通道与空间注意力，增强显著性。
  - **扩散精炼（DR）**：迭代式卷积+CBAM+残差连接的多步精炼，逐步优化特征表征。
- **注意力知识迁移（预测级蒸馏）**：仅当教师模型的预测比学生模型更准确时，才允许蒸馏损失生效。具体通过：
  - **图像级选择**：仅在该图像上教师损失低于学生时，才进行蒸馏。
  - **像素级选择**：进一步筛选出教师更准确的像素进行蒸馏。
  - **混合选择**：图像级与像素级掩模的逐元素相乘，实现最精细的过滤。
  - 蒸馏损失为带温度的KL散度，并归一化所选像素数量。
- **学生损失设计**：学生模型在细数据上联合优化二元交叉熵（BCE）、Dice损失、结构相似性（SSIM）损失以及基于Sobel边缘权重的边界损失，强化边界细节。
- **训练数学形式**：最终优化学生参数 \(\theta_S\) 最小化 \(L_{\text{total}}(D_f) = L_{\text{student}} + L_{\text{distill}}\)，其中 \(L_{\text{student}}\) 为上述四部分组合，\(L_{\text{distill}}\) 为混合选择的KL散度。

### 6. 主要结论与发现
- MineC2FNet在细粒度测试集上达到92.33%的Acc和73.64%的mIoU，mIoU显著优于所有对比方法，尤其在边界绘制上优势明显。
- 注意力蒸馏机制是核心驱动力：混合选择策略防止了粗域噪声的负迁移，相比无蒸馏或标准蒸馏提升巨大（mIoU提升超5.4个百分点）。

- 模型在不同气候区域均表现稳健，但在数据极少的寒冷区域有所下降。

### 7. 优点
- **创新性问题转化**：首次将“粗边界”与“细边界”之间的知识迁移定义为领域增量学习任务，为采矿遥感分割提供了新视角。
- **双重注意力蒸馏**：在特征和预测两个层面进行选择性知识迁移，有效抑制噪声，解决了粗标注的致命缺陷。
- **细粒度边界增强**：专门设计边界损失和扩散精炼模块，使模型能够习得复杂不规则的真实矿界。

- **实验系统完整**：对比覆盖主流范式，消融细致，鲁棒性分析（气候区、波段）支撑结论可信度。

### 8. 不足与局限
- **任务局限为二值分割**：当前仅区分“采矿”与“非采矿”，未能识别内部功能分区（如尾矿库、矿坑），限制了精细环境监测的深度。

- **粗数据筛选依赖启发式**：基于最小面积对齐的筛选方法简单，可能引入未知偏差，且未探讨在其他粗粒度任务上的迁移性。
