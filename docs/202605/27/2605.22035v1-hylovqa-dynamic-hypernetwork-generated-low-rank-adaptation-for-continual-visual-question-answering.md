## 摘要
持续视觉问答（VQA）需要从非平稳的视觉输入和问题流中学习，同时保留过去的知识。大多数先前方法通过更新大部分共享的参数集来适应，这往往导致跨层任务干扰，阻碍对当前任务和对象的精确适应。为了解决这一局限性，我们提出了HyLoVQA。它维护了一个抗漂移的锚点记忆库，该记忆库存储视觉对象和文本任务的内容，并使用当前输入特征进行更新。以检索到的锚点为条件，超网络生成轻量级的低秩适应（LoRA）适配器，从而确保参数效率，使模型能够动态适应每个任务和对象。此外，我们设计了一种对齐损失，将特征空间中的语义差异与参数空间中的功能变化对齐，从而约束LoRA适配器保持专注于当前任务和对象。在VQA v2和NExT-QA数据集上进行的标准与组合设置下的大量实验表明，HyLoVQA优于先前的最先进方法。

## Abstract
Continual Visual Question Answering (VQA) requires learning from non-stationary streams of visual inputs and questions while preserving past knowledge. Most prior methods adapt by updating a largely shared parameter set. This often leads to cross-level task interference, hindering accurate adaptation to the current task and object. To address this limitation, we propose HyLoVQA. It maintains a drift-resilient memory bank of anchors. The bank stores the content of visual objects and textual tasks, and they are updated using current input features. Conditioned on retrieved anchors, a hypernetwork generates lightweight Low-Rank Adaptation (LoRA) adapters. This ensures parameter efficiency, allowing the model to adapt to each task and object dynamically. Additionally, we formulate an alignment loss that aligns semantic discrepancies in the feature space with functional changes in the parameter space, thereby constraining LoRA adapters to remain focused on the current task and object. Extensive experiments on VQA v2 and NExT-QA under both standard and compositional settings demonstrate the superiority of HyLoVQA over prior state-of-the-art methods.

## 1. 论文的核心问题与整体含义

持续视觉问答（Continual VQA）要求模型在视觉输入和问题随时间不断变化的非平稳数据流中学习，同时避免对旧知识的灾难性遗忘。现有方法大多通过更新大部分共享参数来适应新任务，这会带来严重的**跨层级任务干扰**——先前学到的任务可能干扰当前任务，且难以对当前的**任务类型**（如“计数”）和**视觉对象**（如“猫”）进行精准的动态适配。  
该问题导致模型在回答问题时容易产生任务歧义和对象歧义，从而给出错误答案。  
因此，论文旨在设计一种能做到**参数高效、动态、抗干扰**的持续学习框架，使模型能够针对每个输入样本的“任务–对象”组合进行定制化适应，同时保持对过去知识的稳定记忆。

## 2. 方法论

HyLoVQA 由三个核心组件构成，整体结构见图2（论文Figure 2）。

### （A）抗漂移记忆锚点库（DMA）
- 维护两个独立的紧凑锚点集合：**视觉锚点** \(P_v\)（存储视觉对象特征）和**文本锚点** \(P_q\)（存储任务语义特征）。
- 对每个新样本，通过余弦相似度分别检索最相关的视觉锚点和问题锚点。
- 采用**动量更新**的方式逐步演化被检索到的锚点：
  \[
  p_{v,k^*} \leftarrow \alpha p_{v,k^*} + (1-\alpha)f_v,\quad
  p_{q,k^*} \leftarrow \beta p_{q,k^*} + (1-\beta)f_q
  \]
  未检索到的锚点保持不变，从而保证记忆库在漂移环境下的稳定性。
- 将检索到的锚点拼接为实例上下文 \(z_{inst}\)。
- 额外引入**记忆一致性损失** \(L_{mem}\)，鼓励全局特征与被更新锚点保持一致，进一步抗漂移。

### （B）超网络生成LoRA模块（HyGen）
- 以实例上下文 \(z_{inst}\) 和可学习的层嵌入为条件，让一个**超网络** \(H_{\phi}\) 为每一层交叉注意力动态生成低秩矩阵 \(A_{\ell,X}, B_{\ell,X}\)（\(X \in \{Q,K,V\}\)）。
- 将这些LoRA因子以低秩形式注入骨干网络的固定投影矩阵：
  \[
  W_{\ell, \text{adp}, X} = W_{\ell, \text{base}, X} + \lambda (B_{\ell,X}A_{\ell,X})^\top
  \]
  从而实现**样本级别、任务/对象特异的参数适配**，同时保持参数总量极少。
- 同时将检索到的锚点作为全局上下文token拼接到Q和V序列中，引导注意力侧重当前任务与对象。

### （C）语义–功能对齐损失（SF Alignment loss）
- 定义**语义距离** \(D_{sem}\)：当前实例上下文 \(z_{inst}\) 与原始多模态特征 \(z_{raw}\) 的余弦距离。
- 定义**功能距离** \(D_{func}\)：由 \(z_{inst}\) 和 \(z_{raw}\) 分别生成的LoRA参数向量之间的归一化 ℓ2 距离。
- 对齐损失鼓励两者一致：
  \[
  L_{align} = \big(D_{sem}(z_{inst}, z_{raw}) - D_{func}(\theta_{inst}, \theta_{raw})\big)^2
  \]
  该损失迫使LoRA适配器的变化幅度与输入语义变化相匹配，避免产生偏离当前样本的无效更新。

最终训练目标为：
\[
\mathcal{L} = \mathcal{L}_{CE} + \gamma_1 \mathcal{L}_{mem} + \gamma_2 \mathcal{L}_{align}
\]

## 3. 实验设计

### 数据集与设定
- **VQA v2**：包含超过20万张COCO图像和110万问答对，按问题类型划分为10个顺序任务（识别、位置、计数、颜色、动作等）。
- **NExT‑QA**：视频问答基准，要求时序与因果推理，划分为8个顺序任务（CW, TN, TC, DL, DB, DC, DO, CH）。
- 采用两种测试范式：
  - **标准测试**：评估已见任务–对象组合的性能。
  - **新颖组合测试**：评价模型对训练中未出现过的技能–概念组合的泛化能力（分组留一验证）。

### 评估指标
- **最终平均性能（AP）**：所有任务结束后的平均准确率。
- **平均遗忘（AF）**：对早期任务性能下降的衡量，值越小越好。

### 实现细节

- 优化器Adam，学习率3e‑5，梯度裁剪5，warmup比例0.1，损失权重 \(\gamma_1, \gamma_2\) 从{0.1,1,10}中调节。

## 6. 主要结论与发现

- HyLoVQA在**所有测试设定**中均取得最优AP和最低AF，显著超越包括VQACL、CLT‑VQA在内的先前最佳方法。例如VQA v2标准测试AP达到45.41%，新高约+4.7%；NExT‑QA新颖组合测试AP提升+7.19%。
- 各组件的消融表明：仅用DMA时性能下降且遗忘升高，加入HyGen后显著提升，再加入Alignment损失得到最佳平衡，验证了**动态LoRA和对齐约束**的必要性。
- 通过t‑SNE可视化发现，HyLoVQA的样本表征具有更紧凑的类内聚集和更清晰的类间分离，说明其有效降低了跨任务表征纠缠。
- 随着记忆库容量增大，AP稳步上升、AF下降，且始终优于其他需要大量回放缓冲的基线，展示了高效的记忆利用。
- 模态相关动量分析显示，模型能根据不同任务的主导模态调整更新策略（如视觉任务偏好高α，文本任务偏好高β），验证了**抗漂移更新机制**的灵活性。
- 案例研究直观展示了HyLoVQA能通过锚点检索和条件LoRA有效保留颜色、动作等约束，避免退化到通用捷径。
