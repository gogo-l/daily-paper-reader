## 摘要
参数高效微调使得文本到图像扩散模型的快速个性化成为可能，但组合多个自定义概念仍因表示干扰而充满挑战。现有的模块化方法要么依赖昂贵的事后融合，要么冻结适配子空间，这限制了表达能力和概念保真度。为了应对这一权衡，我们提出了序列正则化LoRA（SeqLoRA），这是一个受约束的持续学习框架，通过双层优化联合优化两个LoRA因子。理论上，我们为算法建立了强收敛保证，并将残差层激活建模为矩阵亚高斯过程，以推导出灾难性遗忘的高概率边界。我们进一步证明，从数据中学习LoRA基比冻结基方法能更有效地最小化残差干扰能量。在多概念图像生成上的实验表明，SeqLoRA在多达101个概念上提升了身份保持和可扩展性，同时避免了昂贵的融合，并减少了组合生成中的属性干扰。

## Abstract
Parameter-efficient fine-tuning enables fast personalization of text-to-image diffusion models, but composing multiple custom concepts remains challenging due to representation interference. Existing modular methods either rely on expensive post-hoc fusion or freeze adaptation subspaces, which limit expressiveness and concept fidelity. To address this trade-off, we propose Sequential regularized LoRA (SeqLoRA), a constrained continual learning framework that jointly optimizes both LoRA factors via bilevel optimization. Theoretically, we establish strong convergence guarantees for our algorithm and model the residual layer activations as a matrix sub-Gaussian process to derive high-probability bounds on catastrophic forgetting. We further prove that learning the LoRA basis from data minimizes residual interference energy more effectively than frozen-basis methods. Experiments on multi-concept image generation demonstrate that SeqLoRA improves identity preservation and scalability across up to 101 concepts, while avoiding costly fusion and reducing attribute interference in composed generations.

- **核心问题**：在基于扩散模型的文本到图像生成中，利用参数高效微调（如 LoRA）可以快速实现单概念个性化，但当需要将多个独立学习的概念组合到同一张图像时，会出现严重的**表示干扰**与**属性纠缠**。
- **现有方法的取舍**：
  - **联合训练**（如 Custom Diffusion）需同时访问所有概念数据，不易扩展且存在隐私问题。
  - **梯度融合**（如 Mix-of-Show）需为每个组合重新执行优化融合步骤，非真正模块化。
  - **正交适配**（如 Orthogonal Adaptation）及**持续学习**方法（如 InfLoRA）通过冻结 LoRA 的基矩阵来保证子空间正交，但牺牲了表达能力。
- **根本挑战**：在需要**子空间正交**以消除干扰与需要**优化表达空间**以保持概念保真度之间存在根本性权衡。现有方法未能同时允许自由优化两个 LoRA 因子且强制子空间正交。

## 2. 方法论：SeqLoRA（序列正则化 LoRA）
### 2.1 核心思想
将多概念持续生成建模为**受约束的双层优化问题**：每个新概念在学习时，其 LoRA 基矩阵 `B_i` 必须与所有先前概念的基矩阵正交，同时联合优化 `A_i` 和 `B_i` 以最大化表达力。

### 2.2 关键技术细节
- **约束优化**：在概念 `i` 到达时，最小化去噪损失，并约束 `B_i^T B_j = 0`（对所有 `j < i`）。
- **双层优化框架**：
  - **下层问题**：`A_i^*(B_i) = argmin_{A_i} L_i(A_i, B_i)`，通过二次近似 `\hat{L}_i` 进行一次梯度下降更新：`A_i^{(k+1)} = A_i^{(k)} - \alpha \nabla_{A_i} L_i`。
  - **上层问题**：将更新的 `A_i^{(k+1)}(B_i)` 带入损失得到 `\Phi_i(B_i)`，再构造 `\hat{\Phi}_i` 的二次模型，结合正交约束求解 `B_i`。
  - **交叉黑塞校正**：上层梯度 `\nabla_{B_i} \Phi_i` 包含直接偏导项和通过 `A_i` 对 `B_i` 依赖的间接项（交叉黑塞–向量积），从而捕获参数耦合，提供更丰富的下降方向。
- **闭式投影**：在对 `B_i` 的无约束更新步 `\tilde{B}_i` 后，将其正交投影到先前基的列空间正交补上：`B_i^{(k+1)} = P_{<j}^\perp \tilde{B}_i`。其中 `P_{<j}^\perp` 为投影到 `span{B_1,...,B_{i-1}}` 正交补的矩阵。
- **算法流程（Algorithm 1）**：对每个新概念进行 K 次双层迭代，每轮包含：临时更新 `A` → 计算约化梯度并投影更新 `B` → 最终更新 `A`。所有适配层并行执行。

### 2.3 理论贡献
- **收敛性（Theorem 1）**：在标准光滑性假设下，选取适当步长，算法具有严格单调下降性，且迭代序列收敛至受约束问题的临界点。
- **灾难性遗忘界（Theorem 2）**：将各层残差激活建模为矩阵亚高斯过程，利用 Hanson-Wright 不等式导出高概率遗忘上界。上界由各层的**残差协方差能量** `Tr(P_{B_j}^\perp \Sigma_j)` 主导。最小化该残差能量要求 `B_j` 对齐激活的 top-r 主成分，而学习基矩阵正是隐含地寻找该最大能量子空间，**冷冻随机基则普遍次优**。
