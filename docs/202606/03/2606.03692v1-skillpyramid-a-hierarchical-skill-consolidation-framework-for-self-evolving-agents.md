## 摘要
近期的人工智能智能体能够灵活调用技能以解决复杂任务，但其长期改进在根本上受限于缺乏系统性的技能构建、积累与迁移。尤其在没有统一的技能整合框架时，智能体倾向于在不同任务间冗余构建相似能力，无法将经验有效转化为可复用资产，也难以将任务特定技能泛化至新场景。针对这一局限，我们提出 SkillPyramid，一个通过重用已有技能经验来实现更广泛任务泛化的技能整合框架。SkillPyramid 基于层次化技能拓扑运行，并进一步引入自进化机制，使智能体能够在任务执行过程中组合、验证并纳入新技能。在 ALFWorld、WebShop 和 ScienceWorld 上使用四种骨干模型的实验表明，SkillPyramid 将平均奖励大幅提升 38.0%，并将执行步数减少 27.7%。总体而言，我们的方法将技能集合从静态资源池转变为动态进化系统。

## Abstract
Recent AI agents can flexibly invoke skills to solve complex tasks, but their long-term improvement is fundamentally constrained by a lack of systematic skill construction, accumulation, and transfer. In particular, without a unified framework for skill consolidation, agents tend to redundantly construct similar capabilities across different tasks, are unable to effectively transform experience into reusable assets, and struggle to generalize task-specific skills to novel scenarios. To address this limitation, we propose SkillPyramid, a skill consolidation framework that reuses existing skill experience for broader task generalization. Operating on a hierarchical skill topology, SkillPyramid further introduces a self-evolution mechanism that enables agents to compose, validate, and incorporate new skills during task execution. Experiments on ALFWorld, WebShop, and ScienceWorld across four backbone models show that SkillPyramid substantially increases the average reward by 38.0% and reduces execution steps by 27.7%. Overall, our method transforms a skill collection from a static resource pool into a dynamic evolution system.

现有大语言模型（LLM）驱动的智能体虽然能够调用“技能”来完成复杂任务，但在长期自主改进中面临根本性瓶颈：**缺乏系统化的技能构建、积累与迁移机制**。静态、扁平化的技能库导致智能体在不同任务间重复学习相似能力，任务经验难以转化为可复用的资产，也难以将特定任务技能泛化到未见任务。本文提出 **SkillPyramid**，一个 **层次化技能整合与自进化框架**，旨在将技能的集合从静态资源池转变为不断生长的动态演化系统，通过结构化的复用与依赖关系来提升智能体的跨任务泛化和交互效率。

## 2. 方法论核心思想与技术细节
SkillPyramid 的想法是将现有技能组织成金字塔形的多层结构：低层承载细粒度的可复用原子能力，高层归纳出可组合的抽象任务求解模式。其构建与进化分为以下核心模块：

- **技能金字塔构建**  
  给定初始技能集合 `S = {s₁,...,sₙ}`，通过 **关系分析器** 和 **关系构建器** 迭代完成：
  - **粗分组（Coarse Grouping）**：仅根据技能名称与描述，将潜在相关的技能划分为粗粒度组。
  - **细粒度关系分析**：在每个组内，深度检查技能内容，给出关系构建指派 `D = {(gₖ, τₖ, eₖ)}`，指明技能子集 `gₖ` 及其关系类型 `τₖ`（向下原子提取或向上抽象归纳），并附上自然语言证据 `eₖ`。
  - **向下原子提取**：对于 `τₖ = Downward Atomic Extraction`，构建器 `B_atom` 从一组技能 `gₖ` 中提取共享的最小可复用能力，形成**原子技能** `aₖ`；然后重写原始技能使其显式引用该原子技能（`s_i' = Rewrite(s_i, ρ(aₖ))`）。原子技能被放置于比源技能更低一层。
  - **向上抽象归纳**：对于 `τₖ = Upward Abstract Induction`，构建器 `B_abs` 归纳出一组技能的**抽象技能** `uₖ`，描述高层任务结构或模式，而非具体执行细节。抽象技能位于比源技能更高一层。
  - 为了消除冗余，高度相似的原子技能会被合并，能够完全覆盖其他技能者会被直接作为可复用模块。

- **任务驱动的技能创建**  
  面对新任务指令 `x`，**技能创建器**从当前金字塔中检索相关技能 `R(x)`，并分两阶段合成新技能：
  - **框架构建**：优先使用抽象技能勾勒任务结构、子目标和决策逻辑。
  - **细节实例化**：优先使用原子技能填充具体操作、输入输出、校验规则等，形成最终可执行的技能 `ŝ = C_create(x, R(x), P)`。若已有技能完全覆盖，则直接复用。

- **自进化机制**  
  新创建的技能 `ŝ` 不会简单附加到库中，而是通过关系分析器检索金字塔中与 `ŝ` 潜在相关的已有技能，并由关系构建器构建新的复用与依赖关系 `ΔPₜ`，然后增量更新金字塔 `P_{t+1} = Update(P_t, ŝ, ΔPₜ)`。这样，金字塔持续进化而无需从零重建。

整个方法论以自然语言技能为操作单元，所有关系、原子能力和抽象模式均表现为结构化的技能描述，并由骨干 LLM 驱动分析、构建与合成。

- **性能全面提升**：SkillPyramid 在所有环境和骨干模型上均获得最高平均奖励（73.7），比 ReAct+Skills 高约 8 个百分点，执行步数平均减少 27.7%。

- **原子与抽象技能各司其职**：原子技能对低层操作密集型任务帮助更大，抽象技能对多步依赖和组合型任务帮助更明显。

- **对噪声技能的鲁棒性**：在 GAIA-Lite 上，将网络挖掘的大量技能组织为金字塔后，准确率和效率均优于扁平使用，说明金字塔整合方式能提升大规模、噪声环境下技能的有效性。
