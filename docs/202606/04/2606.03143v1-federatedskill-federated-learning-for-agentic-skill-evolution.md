## 摘要
现代大语言模型智能体越来越依赖技能库来处理复杂任务，这使得技能进化成为自我提升的主要驱动力。然而，孤立的单用户任务流缺乏构建全面技能所需的多样性。虽然跨用户协作能够克服这一数据瓶颈，但当前的轨迹共享方法会损害用户隐私，并强加一个统一的全局库，无法适应客户端异构性。我们提出了FederatedSkill，一个用于协作智能体进化的隐私保护框架。FederatedSkill超越了原始轨迹共享，利用语义技能差异——即基于局部库的结构化补丁——作为通信的基本单元。在服务器端，一个进化智能体聚合这些补丁，动态建模客户端特定的能力边界，从而促进严格个性化的技能进化，而非次优的全局平均。在20个不同的智能体任务族上评估，FederatedSkill相较于自进化基线展现出显著提升，成功率最高提升了44.4%，计算成本降低了37.5%。

## Abstract
Modern LLM agents increasingly rely on skill libraries to handle complex tasks, making skill evolution a primary driver of self-improvement. However, isolated single-user task streams lack the diversity required to build comprehensive skills. While cross-user collaboration can overcome this data bottleneck, current trajectory-sharing approaches compromise user privacy and impose a uniform global library that fails to accommodate client heterogeneity. We introduce FederatedSkill, a privacy-preserving framework for collaborative agent evolution. Moving beyond raw trajectory sharing, FederatedSkill utilizes semantic skill diffs, structured patches over local libraries, as the fundamental unit of communication. On the server side, an evolution agent aggregates these patches to dynamically model client-specific capability boundaries, facilitating strictly personalized skill evolution rather than a suboptimal global average. Evaluated across 20 distinct agent task families, FederatedSkill demonstrates substantial gains over self-evolving baselines, achieving up to a 44.4% increase in success rate and a 37.5% reduction in computational cost.

### 2. 论文提出的方法论

- **核心思想**：不走轨迹共享的老路，而是在客户端完成技能提炼，仅上传结构化的**技能补丁（δᵢᵗ）**，服务器端基于补丁语义和客户端画像完成个性化合并与更新。
- **客户端执行与补丁蒸馏**
  - 本地代理基于当前技能库执行一批任务，收集轨迹与奖励。
  - 本地补丁生成器（与执行代理同骨干）将轨迹压缩为补丁，格式包含：新增/修改的文件（upserts）、待删除路径、任务奖励、一句话理性摘要。
  - 隐私保护设计：补丁中不含原始交互文本、任务专有值或一次性输出；所有路径经过安全校验。
- **服务器端个性化演化**
  - 将服务器聚合建模为一个**部分可观测马尔可夫决策过程（POMDP）**：观测仅为客户端资料和技能补丁，隐状态需推断各客户端的能力边界。
  - 演化代理分两阶段工作：
    1. **演化规划**：构建**能力矩阵**（工作流×客户端，标记为覆盖/吸收/破损/缺失），维护**两级记忆**（家庭级共享记忆与客户端私有记忆），并生成个性化演化指令（吸收、修复、重构）。
    2. **库演化执行**：根据指令，对每个客户端独立融合补丁、调整样式，生成下一轮技能库。
  - 个性化关键在于：对成功补丁并非直接复制，而是根据客户端模型/框架的*风格适配*进行吸收或改写。

### 6. 论文的主要结论与发现

- **性能提升显著**：FederatedSkill 在 20 个任务族上，成功率较自进化基线平均提升，最高达 **44.4%**；计算成本最高降低 **37.5%**。
- **异构场景鲁棒**：在跨不同模型、甚至跨不同 Harness 的极端异构设置下依然有效，平均增益分别达 **+5.82 pp** 和 **+4.82 pp**。
- **个性化至关重要**：使用单一全局技能会导致性能下降，而个性化演化可为每个客户端带来 **+9.8 到 +12.2 pp** 的提升。
- **缓解库膨胀与停滞**：自进化容易导致部分模型库无节制膨胀，部分模型停滞；FederatedSkill 通过跨客户端去冗和保守准入将库大小稳定在合理区间。
- **极低通信开销**：所有家族整个联邦过程仅传输约 **3.5 MB**，适合边缘部署和受约束网络环境。
- **强隐私保护**：技能补丁仅泄露 **5.08%** 的敏感实体，且个性化更新中泄露率低至 **0.09%**，与负对照无统计差异。

- **隐私设计巧妙**：通过语义蒸馏将隐私保护内建于协议中，轨迹完全不离客户端，且经验证几乎无敏感信息残留。
- **真正个性化**：突破传统联邦学习在参数级或统一全局库的局限，动态建模能力边界，适配不同模型和工具链的风格差异。

### 8. 不足与局限

- **客户端规模受限**：受限于计算资源，实验仅使用三个客户端，大规模（数十至上百）异构智能体的协同行为尚待探索。
