## 摘要
教育对话对于研究而言是一种宝贵但敏感的资源：捕获真实学习过程的转录文本往往同时包含个人身份信息（PII），这些信息与课程内容纠缠在一起，例如“Riemann”既可能指一个真实的学生，也可能指一个数学概念。现有方法在数据治理与准确性之间难以两全。商用大语言模型（LLM）能够处理这种歧义，但需要将学生数据发送给第三方，而本地命名实体识别（NER）系统虽能确保数据治理，却会过度删改课程术语。我们提出一种全本地级联框架，将去标识化从开放式的实体识别重新定义为受限的隐私分类。一个召回优先的并集提议器结合两个轻量级编码器和确定性规则，以过度生成候选片段；随后，一个上下文感知的审核器利用周围的对话和说话人角色，对每个候选片段做出二分决策：删改或保留。我们在两个大型平台的数学辅导转录文本上，将三种审核器配置与同家族仅LLM的基线以及一个商用API进行评估。最强的本地配置达到了0.958的宏F1分数，而同家族仅LLM基线为0.767，商用API为0.706，且完全在单台笔记本电脑上运行。在一个关于课程-个人姓名歧义的专项挑战集上，相同配置的F1仅下降0.03，而规模较小的审核器下降0.19至0.25。这些结果表明，对于教育去标识化，问题的形式化比模型规模更为重要。

## Abstract
Educational dialogue is a valuable but sensitive resource for research: the same transcripts that capture authentic learning often capture personally identifiable information (PII) entangled with curricular content, where "Riemann" may refer to a real student or to a mathematical concept. Existing approaches force a tradeoff between governance and accuracy. Commercial Large Language Models (LLMs) can handle this ambiguity but require sending student data to third parties, while local named entity recognition (NER) systems preserve governance but over-redact curricular terms. We propose a fully local cascade framework that reframes de-identification from open-ended entity recognition to constrained privacy triage. A recall-first union proposer combines two lightweight encoders with deterministic rules to over-generate candidate spans; a context-aware reviewer then makes a binary Redact/Keep decision for each candidate using surrounding dialogue and speaker role. We evaluate three reviewer configurations against same-family LLM-only baselines and a commercial API on math tutoring transcripts from two large platforms. The strongest local configuration reaches 0.958 macro F1, compared with 0.767 for a same-family LLM-only baseline and 0.706 for the commercial API, while running entirely on a single laptop. On a targeted challenge set of curricular-personal name ambiguity, the same configuration degrades by only 0.03 F1 versus 0.19 to 0.25 for smaller reviewers. These results suggest that for educational de-identification, problem formulation matters more than model scale.

### 2. 论文提出的方法论

- **核心思想**：将去标识化从传统的开放式命名实体识别重构为“召回优先的候选生成 + 上下文敏感的删改/保留二分类”级联框架。第一阶段过度生成所有可能的PII候选片段，第二阶段则依据对话上下文和说话人角色，对每个候选仅作出“删改”或“保留”的决策。
- **关键技术细节**：
    - **第一阶段（Span Proposer）**：由两个轻量级编码器（DeBERTa-v3-base 和 ModernBERT-base）的并集输出加上确定性正则表达式规则构成。编码器采用BIO序列标注进行微调，联合输出所有可能为PII的片段；正则规则负责高精度结构化标识符（如邮箱、电话、URL等）。该阶段以牺牲精确率为代价最大化召回率。
    - **第二阶段（Cascade-Aligned Reviewer）**：审核器接收候选片段及其周围对话上下文、说话人角色等，输出二分类标签“REDACT”（删除）或“KEEP”（保留）。微调时，根据候选与人工标注的重叠自动生成训练标签：重叠的标为REDACT，无重叠的标为KEEP，将开放式NER转为受限的隐私分类任务，降低任务复杂度。
    - **审核器配置**：评估了三种审核器——RoBERTa（125M参数，全量微调）、Gemma E4B-it（4B参数，使用LoRA）、Gemma-4-31B-it（31B参数，使用LoRA）。它们接受上下文感知的提示，包含数学应用题中虚构角色名应保留的显式规则。
    - **最终决策**：正则规则直接命中的候选被自动标记为REDACT并跳过审核器；编码器提出的候选经由审核器判断。

### 6. 论文的主要结论与发现

- **级联框架显著优于仅LLM和商用API**：在标准测试集上，最强配置Union + Gemma 31B达到宏F1 0.958，远高于同家族LLM仅基线（0.767）和商用Gemini 3.1 Pro（0.706）。即使较小的4B审核器也获得0.943 F1。
- **问题形式化比模型规模重要**：将任务重构为候选片段上的“删改/保留”决策，使小模型也能有效运作，而直接让LLM从全文中提取实体的方式存在严重的召回坍塌，尤其在长对话上（4B基线在长短对话召回率从0.54下降至0.11）。
- **鲁棒性差异**：在姓名歧义的挑战集上，Gemma 31B审核器的F1仅下降0.03（最终0.932），而4B审核器下降0.19，RoBERTa审核器下降0.25。这表明对于复杂的上下文歧义，足够大的模型容量是必要的。
- **全本地部署可行性**：整个最佳管线可在单台笔记本电脑上训练和推理，训练数小时，无数据外泄，满足严格的数据治理需求。

### 7. 优点

- **创新的任务形式化**：将去标识化从“实体提取”改为“候选验证”+“隐私二分决策”，精准应对教育场景的核心难点，有效平衡召回与精确率。
- **全本地、隐私保护的设计**：所有处理均在本地完成，不依赖任何外部API，消除了数据外泄风险，对教育机构极具吸引力。
- **详尽的对比与压力测试**：与同家族LLM的直接对比隔离了问题形式化的影响；专门构建的歧义姓名挑战集直击本课题的典型失败模式。
- **资源友好性**：在消费级笔记本上实现SOTA性能，展示了实用性，而非仅停留在理论或高算力场景。
- **方法论透明度**：详细报告了超参数、提示词文本、多种子均值和方差，并进行了覆盖度审计和错误分析，可复现性强。

### 8. 不足与局限

- **领域局限性**：仅针对英语数学辅导对话，对其他学科、其他语言、不同年龄组或教学模式的普适性尚未验证。
- **推理延迟**：级联结构相比单次推理的检测器增加了延迟（虽批量处理仍可接受），对实时应用可能存在影响。
- **硬件基准特定**：部署成本测量基于Apple Silicon的统一内存架构，在离散GPU平台上的表现可能不同。
- **挑战集规模与代表性**：歧义挑战集是有目的构造的（130段对话），并非随机抽样，其结果应视为压力测试，而非全场景代表性估计。
- **审核器捷径行为**：错误分析揭示RoBERTa审核器主要依赖简单的词汇捷径（如大写单词、知名概念）进行保留决策，而非深度上下文理解，这可能在分布外应用中导致“错觉式”保留或删除。
- **长对话中仅LLM基线的召回坍塌原因**：虽推测为注意力预算限制，但未严格排除输出长度饱和、格式约束等替代解释。
