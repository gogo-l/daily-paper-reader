## 摘要
大语言模型（LLM）的机器遗忘旨在移除指定知识，同时保留模型其余能力。然而，遗忘与保留知识之间的界限往往模糊，因为相关甚至遥远的信息可能在模型中相互纠缠。本文从数据中心的视角研究LLM遗忘，测量遗忘效应如何从遗忘集向同领域及远领域知识传播。我们发现一致的衰减模式：附带损害在遗忘集附近最强，随语义距离增大而减弱，但不会在领域边界消失。我们进一步探讨此类损害能否在遗忘执行前进行审计。我们将遗忘集审计形式化为一种预遗忘预测任务，并分析哪些数据特征最能预示下游损害。结果表明，遗忘集与评估集之间的交互特征提供了最强信号，表明附带损害在模型更新发生前已部分反映于数据几何中。这些发现将遗忘集审计定位为一种早期预警工具，可用于识别有风险的遗忘运行并设计更可靠的遗忘流程。

## Abstract
Machine unlearning for large language models (LLMs) aims to remove specified knowledge while preserving the rest of the model's capabilities. However, the boundary between knowledge to forget and knowledge to retain is often unclear, since related and even distant information may be entangled in the model. In this paper, we study LLM unlearning from a data-centric perspective and measure how unlearning effects propagate from the forget set to same-domain and distant-domain knowledge. We find a consistent decay pattern: collateral damage is strongest near the forget set, weakens with semantic distance, but does not disappear at domain boundaries. We further ask whether such damage can be audited before unlearning is executed. We formulate forget-set auditing as a pre-unlearning prediction task and analyze which data features are most predictive of downstream damage. Our results show that interaction features between the forget set and evaluation set provide the strongest signals, suggesting that collateral damage is partly reflected in data geometry before model updates occur. These findings position forget-set auditing as an early warning tool for identifying risky unlearning runs and designing more reliable unlearning procedures.

### 论文核心问题与整体含义
- **研究背景**：大语言模型（LLM）的机器遗忘旨在移除特定知识（如隐私、有害内容），同时保持模型整体能力。然而，遗忘特定数据往往会无意中损害语义相关甚至无关的保留知识，即产生“附带损害”。
- **核心问题**：现有遗忘评估大多仅做事后汇总指标检测，未能精细刻画损害如何从遗忘集向同领域和远领域知识传播，也无法在遗忘前预判潜在风险。因此，论文提出两个关键研究问题：(1) 遗忘影响如何沿语义层次扩散？(2) 能否在遗忘执行前，仅凭数据特征就预测附带损害？
- **整体含义**：该工作把“遗忘集审计”定位为一种预遗忘早期预警工具，旨在帮助从业者筛选高风险遗忘候选集、合理分配评估资源，从而设计更可靠的遗忘流程。

### 论文提出的方法论
- **三层遗忘影响测量框架**（RQ.1）
  - 将评估知识组织成三层：
    - `L1`：遗忘集本身，代表预期内遗忘效果。
    - `L2`：与遗忘集同领域但未用于遗忘的保留知识，代表局域附带损害。
    - `L3`：来自完全不同领域的知识，代表远距离非预期遗忘。
  - 利用**困惑度比率**（遗忘后与遗忘前PPL之比）量化每层损害，形成三元组 `y = (L1, L2, L3)`。
- **预遗忘影响审计**（RQ.2）
  - **任务形式化**：将审计定义为监督回归问题，输入为 `(遗忘集 D_f, 评估集 D_e)` 对，输出为附带损害比 `ρ_{f,e} = log(PPL_{after}^e / PPL_{before}^e) / log(PPL_{after}^f / PPL_{before}^f)`，该比值度量从遗忘集泄露到评估集的损害程度。
  - **约束**：审计器仅能使用遗忘前即可提取的数据特征，不得访问梯度、遗忘后检查点或任何事后度量。
  - **特征工程**：从三个层面构造80维特征向量（见表3）：
    - 遗忘集内在特征（文本长度、嵌入紧密度、词汇多样性等）；
    - 评估集内在特征；
    - **遗忘–评估交互特征**（如质心余弦相似度、欧氏距离、长度比率、词类比率等），这是预测信号的核心来源。
  - **审计模型**：训练岭回归、随机森林和XGBoost三种回归器预测 `ρ_{f,e}`。
  - **评估方式**：采用留一域交叉验证（LODO CV）和完全留出的不可见领域测试（Held-out Test），确保模型没有见过被审计遗忘集所在领域。

### 论文的主要结论与发现
- **遗忘影响呈现三层空间衰减，但不消失**：
  - 平均困惑度比率严格满足 `L1 > L2 > L3`，损害随与遗忘集的语义距离增大而递减，但即使在远领域层（L3）仍有可观测损害。
  - 损害幅值高度依赖算法（GA最激进，NPO和UNDIAL温和），但三层排序关系在所有算法和模型上保持。
  - 同一算法和超参数下，不同遗忘集造成的损害差异显著（跨度可达2.15倍），说明遗忘集本身应成为事前审计对象。
- **附带损害可以从数据几何中预测**：
  - 审计任务整体可行，UNDIAL最易预测，NPO最难；即使在最困难设置下，排序相关性仍保持在0.5以上（图6）。
  - **交互特征主导预测**：质心欧氏距离、余弦相似度以及长度、词汇比率的跨集比值是最强预测信号，而单集内在特征贡献较小。
  - 审计器能对评估集风险成分变化做出敏感反应，而非捕捉随机噪声。
- **预遗忘审计具有实际应用价值**：虽然不能完全替代最终评估，但可作为轻量级筛选工具，对候选遗忘集进行风险排序，从而指导计算资源分配和保留数据补充。

### 不足与局限
- **模型与算法覆盖面有限**：
  - 仅在7B/8B指令微调模型上验证，未涉及更大规模模型或基础预训练模型。
  - 未测试其他重要遗忘方法（如表示层的RMU），其特征有效性可能在不同干预深度下变化。
- **评价指标单一**：损害衡量仅依赖困惑度，未评估下游任务表现、生成质量、事实一致性或安全性等方面。高困惑度不一定等同于实际行动失效。
- **实验设计固定化**：
  - 采用固定的超参、固定的三层定义和聚类划分，现实场景中边界更为模糊，可能需要动态调参。

- **审计目标约束**：损害比ρ的定义强依赖于对遗忘集的自评估，若遗忘集本身困惑度变化极小（如某些保守算法），比率可能不稳定或失真。
