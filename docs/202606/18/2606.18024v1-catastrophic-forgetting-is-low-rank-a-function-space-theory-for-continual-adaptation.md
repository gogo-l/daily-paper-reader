## 摘要
持续适应中的灾难性遗忘通常通过参数漂移、重放或蒸馏来研究，但这些视角并未识别出哪些输出空间方向是脆弱的。我们在 NTK 机制下给出一个函数空间解释：新任务训练通过跨任务核诱导旧任务预测漂移，从而在任何新任务梯度步之前给出了遗忘向量的闭式预测器。在冻结骨干、线性头部的 PEFT-CL 中，模型在可训练参数上是线性的，该预测器在数值精度上是精确的；对于非线性适配器或全微调，它是一个局部 NTK 近似。同样的表达式揭示了遗忘集中在少量旧任务 NTK 特征模上，并在冻结线性头部下给出了脆弱秩的 Kronecker 缩放规则。这些结果阐明了与先前 NTK 重叠理论的关系，解释了为什么参数空间正则化器可能遗漏输出空间干扰，并启发了一种有针对性的谱正则化器。

## Abstract
Catastrophic forgetting in continual adaptation is usually studied through parameter drift, replay, or distillation, but these views do not identify which output-space directions are vulnerable. We give a function-space account in the NTK regime: new-task training induces old-task prediction drift through the cross-task kernel, yielding a closed-form predictor for the forgetting vector before any new-task gradient step. In frozen-backbone linear-head PEFT-CL, where the model is linear in the trainable parameters, the predictor is exact up to numerical precision; for nonlinear adapters/full fine-tuning, it is a local NTK approximation. The same expression reveals that forgetting concentrates in a small number of old-task NTK eigenmodes and under frozen linear heads gives a Kronecker scaling rule for the vulnerable rank. These results clarify the relation to prior NTK-overlap theory, explain why parameter-space regularizers can miss output-space interference, and motivate a targeted spectral regularizer.

### 2. 方法论

- **核心思想**：将灾难性遗忘定义为函数空间中的一个向量 `Δf_A`，即在新任务B训练后，模型在旧任务A上的预测变化。通过NTK线性化假设，推导出该遗忘向量的**闭式解**。
- **关键技术细节**：
    - **NTK线性化**：在旧任务A的最优参数 `θ_A` 处对模型 `f` 进行一阶泰勒展开，使其成为关于参数的线性函数。
    - **遗忘预测器（Proposition 1）**：在NTK机制下，遗忘向量 `Δf_A` 可被精确预测，其表达式为：
        ```latex
        Δf_A = -K_{AB} (K_{BB} + λI)^{-1} r_B
        ```
      其中 `K_{AB}` 是跨任务NTK矩阵，`K_{BB}` 是新任务NTK矩阵，`r_B` 是新任务在参数 `θ_A` 处的残差。该预测器仅依赖新任务训练前就可计算的信息。
    - **精确与近似场景**：
        - **精确**：在“冻结骨干-线性头部”（frozen-backbone linear-head）的参数高效微调（PEFT-CL）设置下，模型对可训练参数是线性的，NTK线性化是恒等式，该预测器在机器精度内完全准确。
        - **近似**：对于非线性适配器（如LoRA）或全量微调，它是一个局部NTK近似。
    - **低秩结构表征**：
        - 遗忘向量 `Δf_A` 位于旧任务NTK `K_{AA}` 的列空间内，其能量集中在 `K_{AA}` 的前几个特征模上，这些方向构成了“**脆弱子空间**”（vulnerable subspace）。
        - **Kronecker缩放法则（Remark 1）**：在冻结骨干-线性头部下，`K_{AA}` 可精确分解为 `I_C ⊗ G`，其中 `C` 是类别数，`G` 是特征格拉姆矩阵。这导致脆弱子空间的秩 `k*` 具有缩放关系：
            ```latex
            k* ≈ C · k_G
            ```
          其中 `k_G` 是 `G` 的有效秩。
    - **谱正则化（Spectral Regularization）**：基于上述理论，提出一种新的正则化方法，在新的任务训练时，仅惩罚在由旧任务 `K_{AA}` 的前 `k` 个特征向量张成的脆弱子空间内的预测漂移，而对其他方向的漂移不加约束，从而在保持可塑性的同时定向抑制遗忘。
