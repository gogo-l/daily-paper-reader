## 摘要
大型语言模型（LLMs）在不遗忘或进行昂贵重新训练的情况下难以整合新知识。我们提出DYNA，一个轻量级框架，它用一个时间知识图谱来增强冻结的LLM，其中事件是节点，时间关系是有向且带时间戳的边。该图谱充当外部、可更新的记忆。在查询时，DYNA通过随机游走和中心性度量检索相关节点，然后增强LLM的响应。在三个时间回忆任务上评估，与微调相比，DYNA减少了约7%的灾难性遗忘，与标准RAG相比，时间排序能力提高了约5%。更高的图谱聚集系数与更好的检索性能相关，表明图谱结构至关重要。贡献：（1）将情景记忆作为时间知识图谱，（2）无需重新训练的LLM增强，（3）图谱属性作为检索性能的预测指标。

## Abstract
Large Language Models (LLMs) struggle to incorporate new knowledge without forgetting or costly retraining. We propose DYNA, a lightweight framework that augments a frozen LLM with a temporal knowledge graph where events are nodes and temporal relations are directed, timestamped edges. The graph serves as an external, updatable memory. At query time, DYNA retrieves relevant nodes via random walks and centrality measures, then augments the LLM's response. Evaluated on three temporal recall tasks, DYNA reduces catastrophic forgetting by ~7% compared to fine-tuning and improves temporal ordering by ~5% over standard RAG. Higher graph clustering coefficients correlate with better retrieval, showing that graph structure matters. Contributions: (1) episodic memory as temporal KG, (2) retraining-free LLM augmentation, (3) graph properties as predictors of retrieval performance.

## 2. 论文提出的方法论
- **整体架构 (DYNA)**：由一个**冻结的 LLM**、一个**时间知识图谱**以及一个**图检索模块**组成，LLM 完全不参与任何参数更新。
- **时间知识图谱构建**：
  - **节点**：每个事件`e_i`为一个节点，存储其文本描述。
  - **边**：根据时间戳添加有向、带时间戳的边，关系类型包括 `before`、`after` 以及 `co-occurs`。
  - **边权重**：基于时间距离计算 `w(v_i, v_j) = exp(-λ|t_i - t_j|)`，λ 为时间衰减超参数，距离越近的事件影响越大。
- **图谱更新与剪枝**：
  - 可随时间不断扩充新事件。
  - 采用**基于时间的剪枝**（去除超过阈值 T_max 的旧节点）和**基于度的剪枝**（去除低连接节点）以维持效率。
- **检索机制**：
  - **种子节点选择**：将查询中的关键词或实体与图中节点进行文本/嵌入相似度匹配，选取 top-k 最相似节点。
  - **随机游走遍历**：从每个种子节点出发，沿时间加权边执行多次随机游走，捕获直接相关与时间上临近的事件。
  - **中心性打分**：对访问过的节点综合计算 `score(v) = α·degree(v) + β·closeness(v) + γ·visit_freq(v)`，结合度中心性、接近中心性和游走频率，以确定最相关节点。
- **查询增强与生成**：将检索到的事件（带时间戳）与原始查询组合成提示词，送入冻结 LLM 生成回答。
- **计算复杂度**：图更新与检索整体与图节点数 `|V|` 成线性关系，适合长期部署。

- **数据集与场景**：

- **对比方法**：

  - 标准检索增强生成 (RAG，基于向量库)

## 6. 论文的主要结论与发现
- DYNA 在时间顺序任务上取得 **71.42% TOA**，比最强基线 DynaGen 高出约 3.28 个百分点。
- 灾难性遗忘率低至 **1.70%**，远优于微调方法的 34.81%，也低于所有知识增强基线。
- 检索精度 P@5 为 50.28%，但 **P@1 仅 21.28%**，表明检索瓶颈在于精确定位最相关节点，而非 LLM 的推理能力。
- 消融实验显示，**随机游走**对性能贡献最大（移除后 TOA 下降 7.59 点），其次为**时间边**（下降 4.37 点），说明时间和图结构均不可或缺。
- 图的结构属性（如聚集系数）与检索性能正相关，可辅助预测记忆效果。

## 7. 优点
- **零重训、轻量级**：LLM 完全冻结，无需任何参数更新或昂贵硬件，实现持续学习。
- **结构化时间记忆**：显式编码 `before`、`after` 等时间关系，直接针对时间推理弱点。
- **检索效率可控**：线性复杂度，结合剪枝策略，适合长期运行的场景。
- **组件贡献明确**：通过消融与敏感性分析，验证了随机游走、时间边、加权等设计的有效性。
- **多基准公平对比**：涵盖近期高质量时序基准，与多种代表性方法比较，结论较可靠。

## 8. 不足与局限
- **检索精度低下**：P@1 仅约 21%，意味着多数情况下最相关事件未被排到首位，成为系统主要瓶颈。
- **隐式推理提升有限**：在 TimeQA Hard 等需要深层时间推理的场景下，对比 DynaGen 的优势缩小至 2.68 个百分点。
- **对短序列无优势**：当事件序列长度小于 5 时，DYNA 与标准 RAG 无显著差异，图构建开销不划算。
- **冷启动问题**：在最初约 300 个事件（稀疏图）阶段，表现弱于基于预训练嵌入的 LDCL。
- **实时性不足**：在 10,000 节点的图上检索耗时 0.9 秒，难以满足需亚秒级响应的实时应用。
- **实验局限性**：仅估算了 LLaMA 3 8B 一个模型；数据集为简化环境，未在含噪声的现实流数据中验证；未与其他大型图记忆架构进行大规模横向成本对比。
