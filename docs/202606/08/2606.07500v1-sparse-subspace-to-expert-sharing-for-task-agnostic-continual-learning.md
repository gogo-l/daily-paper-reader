## 摘要
大型语言模型中的持续学习受到可塑性-稳定性困境的阻碍，获取新能力往往导致对先前知识的灾难性遗忘。现有方法通常统一处理参数，未能区分特定任务知识和共享能力。我们提出面向任务无关持续学习的稀疏专家混合框架（SETA），通过自适应稀疏子空间分解为任务特定专家模块来解决可塑性-稳定性冲突。与标准更新中任务争夺同一组参数不同，SETA将知识分离到独特的专家中：专用于隔离任务特定模式的专家，以及负责捕获共同特征的共享专家。该结构通过自适应弹性锚定和路由感知正则化来维护，两者在权重和路由层面共同保护共享知识，并使得统一的门控网络能够在推理时自动检索正确的专家组合。在多个领域特定基准上的广泛实验表明，SETA在整体性能上相对于最先进的持续学习基线具有竞争力或更优，尤其在LLaMA-2 7B和Qwen3-4B上，早期任务知识的保持和向后迁移得到显著增强。

## Abstract
Continual learning in Large Language Models (LLMs) is hindered by the plasticity-stability dilemma, where acquiring new capabilities often leads to catastrophic forgetting of previous knowledge. Existing methods typically treat parameters uniformly, failing to distinguish between specific task knowledge and shared capabilities. We introduce Mixture of Sparse Experts for Task Agnostic Continual Learning (SETA), a framework that resolves the plasticity-stability conflict through adaptive sparse subspace decomposition into task-specific expert modules. Unlike standard updates, where tasks compete for the same parameters, SETA separates knowledge into unique experts, designed to isolate task-specific patterns, and shared experts, responsible for capturing common features. This structure is maintained through adaptive elastic anchoring and a routing-aware regularization that jointly protect shared knowledge at both the weight and routing levels and enable a unified gating network to automatically retrieve the correct expert combination during inference. Extensive experiments across diverse domain-specific benchmarks demonstrate that SETA achieves competitive or superior overall performance relative to state-of-the-art continual learning baselines, with particularly strong retention of early-task knowledge and improved backward transfer on LLaMA-2 7B and Qwen3-4B.

## 1. 论文的核心问题与整体含义

- **研究背景**：大型语言模型在持续学习场景中面临**可塑性-稳定性困境**——模型在顺序学习新任务时容易发生**灾难性遗忘**，即新知识覆盖旧知识。现有方法（重放、正则化、参数隔离）普遍采用**统一参数更新策略**，无法区分可复用的共享特征与任务独有特征，导致稳定性与可塑性的权衡不理想。
- **核心问题**：如何在**任务无关**（无任务标识）的条件下，自动将稀疏的参数更新解耦为共享知识与任务特定知识，从而在持续学习过程中既能保护历史记忆，又能高效获取新能力。
- **整体含义**：论文提出 **SETA（面向任务无关持续学习的稀疏专家混合框架）**，通过自适应稀疏子空间分解与动态专家演化，从结构上解决参数冲突，为大型语言模型提供一种更鲁棒的持续学习解决方案。

## 2. 论文提出的方法论

- **核心思想**：利用梯度驱动的块级稀疏性，将参数空间分解为**独特专家**（仅与当前任务相关）与**共享专家**（跨任务重叠），并通过弹性锚定与路由正则化保护共享知识，实现无任务标识的自动推理。

- **关键技术细节与流程**：
  1. **稀疏子空间选择（Sparse Subspace Selection）**  
     - 将预训练权重矩阵划分为固定大小子块，通过**动态预热停止准则**与**层归一化梯度评分**识别高重要性块（主要集中在 Value 投影）。  
     - 从第二个任务起，引入**跨任务发散评分**奖励与历史任务梯度分布不同的块，并以对数衰减系数自动调节。  
     - 块预算通过设定的比例 `ρ` 确定，并支持后期任务自然扩展。

  2. **独特专家与共享专家的设计**  
     - 将当前任务的稀疏子空间与历史累积子空间对比：  
       - **独特专家** `E_u`：仅属于当前任务的参数索引（`P_t \ P_{1:t-1}`），冻结以永久保存历史。  
       - **共享专家** `E_s`：与先前任务重叠的参数索引（`P_t ∩ P_{1:t-1}`），用于正向迁移，但需防止语义漂移。

  3. **Split-on-Share 专家演化**  
     - 设计**专家创建阈值 τ_ect** 与**微小残差阈值 τ_trt**，对层间重叠进行拓扑过滤：  
       - 若重叠块数小于 τ_ect，视为噪声并合并回独特子空间。  
       - 若独特残差小于 τ_trt，吸收到共享专家中，避免碎片化。  
     - 通过继承权重初始化共享专家，冻结上一任务独特专家，新任务剩余索引形成新独特专家。

  4. **防止灾难性遗忘的双重策略**  
     - **正交子空间隔离**：训练时冻结所有先前独特专家，仅优化当前共享专家与当前独特专家。  
     - **自适应弹性锚定**：对每个共享专家施加动态正则化系数：  
       ```  
       λ_i(t) = λ_base · ω_i · δ_i(t)  
       ```  
       其中 `ω_i` 与该专家累积服务的任务数成正比，`δ_i(t)` 随权重与快照的位移单调增加（通过 tanh 函数实现自校正）。  
       正则项：`L_reg = Σ_{i∈E_s} λ_i(t) · ||W_i^{(t)} - Ŵ_i||²`

  5. **自适应门控扩展与路由正则化**  
     - **Logit 不变性**：执行 Split-on-Share 时，通过权重继承保持门控 logits 近似不变，避免冷启动。  
     - **路由感知门控正则化**：在训练过程中惩罚向高风险共享专家的路由概率：
       ```  
       L_gate = Σ_{i∈E_s} λ_i · E_x[σ(g_θ(x))_i]  
       ```  
       `λ_i` 复用弹性锚定系数，无新增超参数。

  6. **统一目标函数与任务无关推理**  
     - 训练损失：`L = -Σ log P(y|x;Θ_t) + L_reg + L_gate`，其中 `Θ_t` 仅包含当前任务的可训练参数。  
     - 推理时，门控网络 `W_g` 对所有专家进行 softmax 加权，生成输出：  
       ```  
       y = W_0 x + Σ_k σ_k(xW_g^⊤) ΔW_k x  
       ```  
       无需任务标识，实现全自动路由。

## 6. 论文的主要结论与发现

- SETA 在 **LLaMA‑2 7B** 上取得 OP=28.72%（超过 I‑LoRA 的 27.32%），在 **Qwen3‑4B** 上取得 OP=43.30%（最佳），且 FT 显著低于 EWC、GEM 等方法。  
- 早期任务保留能力突出：例如在 Qwen3‑4B 上，C‑STANCE 最终准确率上升至 63.64%，远高于 EWC（0.2%）和 I‑LoRA（27.2%），表明 Split‑on‑Share 机制有效隔离并保护历史知识。  
- 后向迁移 BWT 普遍为负值，但 SETA 的负值最小，说明新任务对旧任务的破坏最低。  
- SETA 仅需约 1% 的参数即可完成持续适应，且共享专家块数量呈**次线性增长**，避免了容量爆炸。  
- 路由感知正则化能够进一步提升整体 OP 并改善早期任务记忆（提升约 10 个百分点），与权重正则化形成互补。

## 7. 优点

- **新颖的结构解耦**：首次将稀疏子空间选择与 MoE 范式结合，从参数块级别区分共享与独特知识，而非依赖低秩的密集适配器。  
- **自适应机制丰富**：弹性锚定动态调整保护强度，路由正则化无需额外超参数，预热停止准则自动适应任务梯度动态。  
- **任务无关推理**：门控网络完全基于输入内容选择专家组合，无需任务标识，更贴近实际应用。  
- **参数高效**：训练参数增量极小（<1.5%），同时获得竞争性或更优的性能。  
- **消融与分析扎实**：通过热力图、重叠矩阵、范数分布等可视化清晰展示了方法的内部工作机理。
