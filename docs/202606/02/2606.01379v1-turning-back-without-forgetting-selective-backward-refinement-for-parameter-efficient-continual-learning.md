## 摘要
虽然基于提示的参数高效持续学习通过隔离任务特定提示来减轻灾难性遗忘，但这种隔离也限制了后期任务改进早期任务，使得反向知识迁移未得到充分探索。我们提出选择性反向精炼以实现正向反向知识迁移（SABER）来解决这一局限，这是一个无需回放的框架，在基于提示的持续学习中实现受控的反向迁移。SABER 使用基于提示梯度几何和损失分布相似性的互补任务相关性标准来确定何时进行反向精炼是有益的，并通过限制更新到提示参数空间中的非干扰方向来安全地执行精炼。在多个持续学习基准和不同预训练主干（包括 T5-Large、LLaMA 和 Qwen）上的大量实验表明，SABER 始终实现正向反向迁移，同时保持强大的总体平均性能。代码可在 https://github.com/OptMN-Lab/SABER-ICML-2026/ 获取。

## Abstract
While prompt-based parameter-efficient continual learning mitigates catastrophic forgetting by isolating task-specific prompts, this isolation also limits later tasks from improving earlier ones, leaving backward knowledge transfer underexplored. We address this limitation by proposing Selective bAckward refinement for positive Backward knowledge transfER (SABER), a replay-free framework that enables controlled backward transfer in prompt-based continual learning. SABER determines when backward refinement is beneficial using complementary task-correlation criteria based on prompt-gradient geometry and loss-distribution similarity, and how to perform refinement safely by restricting updates to non-interfering directions in the prompt parameter space. Extensive experiments across multiple continual learning benchmarks and diverse pretrained backbones, including T5-Large, LLaMA, and Qwen, demonstrate that SABER consistently achieves positive backward transfer while maintaining strong overall average performance. Code is available at https://github.com/OptMN-Lab/SABER-ICML-2026/.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- 持续学习（CL）需要模型在序列任务上维持对旧任务的良好性能，参数高效微调（PEFT）特别是基于提示的方法（如软提示）通过冻结骨干并仅学习少量任务特定参数来减轻灾难性遗忘。
- 然而，大多数提示式持续学习方法通过严格隔离任务提示来防止遗忘，一旦学习完毕就冻结先前任务的提示，从而阻断了后期任务对早期任务的反向知识迁移（backward transfer），即使任务之间存在共享知识也无法改善早期表现。
- 近年来虽有工作尝试探索反向迁移，但通常依赖数据回放或全局更新，不直接在提示空间中精炼先前学习的提示，导致基于提示的持续学习中反向迁移的缺失。
- 论文旨在提出一个无需回放的框架，在提示空间中实现受控的正向反向知识迁移，即决定何时对先前提示进行反向精炼以及如何安全地进行更新以避免负迁移。

### 2. 论文提出的方法论
- **SABER 框架总览**：选择性反向精炼以实现正向反向知识迁移（Selective bAckward refinement for positive Backward knowledge transfER），包含两个核心部分：任务相关性判别（决定何时精炼）与约束性反向更新（决定如何精炼）。
- **任务相关性度量**：
  - **投影相关性（SABER-P）**：对先前任务 \(T_i\)，用其提示梯度低秩子空间（通过 SVD 获得基底 \(U_i\)）计算当前任务梯度 \(g_{t \to i}\) 的投影占比 \(s_i = \mathbb{E} \left[ \frac{\|U_i U_i^\top g_{t\to i}\|^2}{\|g_{t\to i}\|^2} \right]\)，以及平均梯度的对齐度 \(c_i\)。只有当 \(s_i \ge \tau_s\) 且 \(c_i > 0\) 时，才认为任务相关且有益。
  - **损失分布相关性（SABER-L）**：比较冻结骨干下两个任务损失分布的 Wasserstein 距离 \(d^{(0)}_i\) 与加入任务 \(i\) 的提示后距离 \(d^{(i)}_i\)，定义相似度 \(WSS_i = d^{(0)}_i - d^{(i)}_i\)。若 \(WSS_i \ge \tau_{WSS}\)（固定阈值）则选择该任务进行反向精炼。
- **安全的反向更新**：
  - 将选中的先前提示 \(u_i\) 的梯度 \(g_{t \to i}\) 投影到其受保护子空间的正交补空间：\(\Delta u_i^{\text{orth}} = (I - \tilde{U}_i \tilde{U}_i^\top) g_{t \to i}\)。
  - 受保护子空间 \(\tilde{U}_i\) 初始为任务 \(i\) 的梯度子空间 \(U_i\)，并在每次反向精炼后将已使用的方向扩充进去，确保后续更新依旧非干扰（命题 4.1）。
  - 命题 4.2 证明，在合适步长下，每次安全更新都能不增加当前任务损失，且严格不等式在非零梯度时成立。
- **算法流程（Algorithm 1）**：逐个任务按顺序学习；对当前任务训练新提示 \(u_t\)；通过相关性准则选择要精炼的旧提示集合；冻结其余旧提示；在最后数个 epoch 进行少量受保护的梯度更新；更新旧提示的受保护子空间。

### 7. 优点
- **填补研究空白**：针对提示式持续学习中反向迁移的缺失，提供了新的解决方案。
- **双重安全机制**：通过任务相关性筛选与子空间约束更新，避免了负迁移。
- **无需回放**：完全不需要存储或访问旧任务数据，隐私友好且节省存储。
- **理论支撑**：给出了非干扰性与单调改进的证明，增强方法可信度。
- **模块化与适配性**：可与现有冻结提示池或共享提示框架结合，且支持两种不同粒度的相关性度量，便于按需选择。
- **实验扎实**：多数据集、多骨干、多任务顺序，消融和敏感性分析充分，且对计算开销有定量说明。

### 8. 不足与局限
- **计算与存储开销**：投影版本（SABER-P）需要为每个任务存储梯度子空间和平均梯度，随任务数线性增长；虽然损失版本（SABER-L）更轻量，但相关性信息的精细程度可能较低。
- **阈值敏感性**：虽展示了默认阈值较鲁棒，但仍需预设全局阈值，极端任务分布下可能需要调整。
- **任务类型局限**：实验集中于 NLP 分类和生成任务（SuperNI/Long Sequence），在视觉或多模态连续学习中的表现有待验证。
- **更长序列与混合相似度**：未在极长任务序列（如 >100）上进行评估，也未深入探讨混合相关性的动态调整。
- **与其他 PEFT 方法的兼容性**：目前仅整合在提示式方法上，能否与 Adapter、LoRA 等策略无缝协作尚未探索。
- **初始化影响**：提示初始化方式（指令种子 vs 随机）可能影响性能，但文中仅简单提及，未展开研究。
