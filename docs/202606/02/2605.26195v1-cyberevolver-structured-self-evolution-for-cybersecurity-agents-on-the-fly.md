## 摘要
基于LLM的智能体越来越多地用于网络安全任务，但现有系统大多依赖固定的、人工设计的框架，难以适应不同的目标和失败模式。我们提出 CyberEvolver，一种自我演化的网络安全智能体框架，它根据失败执行尝试的经验迭代地修改自身的框架。网络安全中的自我演化具有挑战性，因为可能的框架变化空间在很大程度上是非结构化的，执行反馈稀疏且常被环境所掩盖，而低多样性的更新可能导致错误在重复迭代中不断累积。CyberEvolver 通过四层可演化智能体架构来解决这些挑战，该架构将框架优化分解为结构化组件；通过轨迹到诊断的机制，将嘈杂的执行日志转换为可操作的修订信号；并采用基于种群的束搜索策略，在演化过程中保持多样化的智能体变体。我们使用四个开源 LLM 在 CTF 挑战、漏洞利用和渗透测试任务上评估 CyberEvolver。在这些设置中，CyberEvolver 平均将种子智能体的成功率提高了 13.6%，并优于六个由人工设计的网络安全智能体以及两个从其他领域改编的自我改进方法。这些结果表明，框架自我演化是为安全测试构建自适应 LLM 智能体的一个有前景的方向。

## Abstract
LLM-based agents are increasingly used for cybersecurity tasks, but most existing systems rely on fixed, human-designed scaffolds that struggle to adapt across diverse targets and failure modes. We introduce \textsc{CyberEvolver}, a self-evolving cybersecurity agent framework that iteratively revises its own scaffold based on experience from failed execution attempts. Self-evolution in cybersecurity is challenging because the space of possible scaffold changes is largely unstructured, execution feedback is sparse and often obscured by the environment, and low-diversity updates can cause errors to compound over repeated iterations. \textsc{CyberEvolver} addresses these challenges with a four-layer evolvable agent architecture that decomposes scaffold optimization into structured components, a trace-to-diagnosis mechanism that converts noisy execution logs into actionable revision signals, and a population-based beam search strategy that preserves diverse agent variants during evolution. We evaluate \textsc{CyberEvolver} on CTF challenges, vulnerability exploitation, and penetration-testing tasks using four open-source LLMs. Across these settings, \textsc{CyberEvolver} improves the seed agent's success rate by $13.6$\,\% on average, and outperforms six human-designed cybersecurity agents as well as two self-improvement methods adapted from other domains. These results suggest that scaffold self-evolution is a promising direction for building adaptive LLM agents for security testing.

### 方法论

CyberEvolver的核心思想是对智能体框架进行**结构化、基于种群的自我演化**，以克服网络安全任务的特殊挑战。其关键技术点如下：

-   **核心思想**：不修改LLM的模型权重，而是将智能体的“框架”（Scaffold）作为进化对象。框架由提示、工具和交互规则构成，通过诊断失败经验并产生变异来迭代改进。
-   **四层可演化架构（Structured Mutation Space）**：
    -   **策略层**：定义智能体的推理框架、规划和假设验证等高层认知行为。
    -   **环境交互层**：规定与Shell、工具等环境交互的可靠规则和语法模式。
    -   **感知层**：负责将原始、嘈杂的执行输出（如ANSI转义序列）转化为LLM可理解的格式化观测。
    -   **领域知识层**：一个可动态加载的“技能库”，包含针对特定漏洞（如SQL注入、SROP）的战术行动手册。
-   **轨迹诊断（Mutation Signal）**：针对网络安全环境反馈稀疏且嘈杂的特点，设计了一个两阶段分析流水线。首先将长轨迹**压缩**为保留关键信息的摘要（保留精确命令、错误地址等）；然后生成一个**结构化诊断报告**，指出失败的根本原因、分类和进展分数（用于比较同一代内的不同变体）。
-   **种群基束搜索（Mutation Diversity）**：为避免演化陷入局部最优或错误累积，采用类似束搜索的机制。每一代保留多个表现较好的“父代”智能体变体，并从每个父代产生多个“子代”变体，通过自然淘汰来维持探索的多样性。

    -   **公平性**：通过统一评估框架、等量预算（16次尝试）和可验证的成功标准（如获取shell、flag），保证了不同方法间的公平比较。
    -   **客观性**：使用了多个不同架构和开发商的开源模型，避免了单一模型偏向性。消融实验表明，移除分层变异、束搜索或结构化诊断均会导致性能下降，验证了各组件的独立贡献。
    -   **局限性考量**：作者坦诚指出，种子智能体的`pass@k`在`k>4`后趋于饱和，因此CyberEvolver超越`pass@16`的成绩并非简单抽样，而是真正的能力突破。

### 主要结论与发现

1.  **显著的能力提升**：CyberEvolver平均将种子智能体的成功率提升了**13.6%**，超越了其通过重复抽样所能达到的`pass@16`上限。这证明它解决了一些固定框架无法企及的任务。
2.  **优于现有方法**：在所有基准测试和模型配置下，CyberEvolver的表现**一致优于**所有人类设计的专家智能体和跨领域自改进方法，显示出结构化演化的优越性。
3.  **变异多样性与有效性**：对演化树的分析表明，CyberEvolver能产生**多样化、有意义的框架变异**，而不仅是近亲繁殖。变异分布在所有四个层面，其中“领域知识层”的“新增”行为是主要驱动力。
4.  **泛化失败案例的归因**：通过对失败案例的深入剖析，发现另一自演化方法HGM失败的原因在于，其不限制变异空间导致生成大量无用工具，且仅依赖二元成功信号难以提供有效引导。

### 优点

-   **问题定义清晰，挑战拆解到位**：准确识别出网络安全自演化面临的“变异空间非结构化”、“信号模糊”和“多样性不足”三大核心挑战，并针对性提出解决方案。
-   **方法论新颖且系统**：四层可进化架构、轨迹诊断和种群束搜索的设计精巧，将进化计算的思想系统地应用于LLM智能体框架优化，而非仅仅是提示词或代码的改写。
-   **实验评估极为扎实**：覆盖多种任务场景、多个主流强大模型和丰富基线，结论令人信服。附录中详尽的提示词、沙箱环境配置和算力信息极大地提升了可复现性。

### 不足与局限

-   **任务类型受限**：当前仅评估了**攻击性安全任务**（渗透、利用），未涉足防御性工作（如事件响应、漏洞修复）。
-   **演化预算固定且较小**：实验默认演化代数（3代）和总尝试次数（16次）相对受限。更大规模的搜索可能会带来不同的效益边界，也可能导致过拟合或收敛问题。
-   **未探索跨目标迁移**：由于现有基准测试中的任务耦合度不够精细，目前尚未研究一个目标上演化出的能力能否迁移到类似的其他目标上。
-   **存在双重用途风险**：论文本身承认，自演化攻击框架的技术具有双重用途，可能被滥用于非授权的攻击活动。
