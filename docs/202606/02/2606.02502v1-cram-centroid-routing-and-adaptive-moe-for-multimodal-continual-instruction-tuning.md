## 摘要
多模态大语言模型通过指令调优在统一的生成框架下整合异构视觉语言任务，但现实部署需要持续扩展能力，使得多模态持续指令调优变得至关重要。现有方法要么用共享参数集更新所有任务，要么为每个新任务分配专属模块。共享更新迫使异构任务相互竞争，导致已学能力遗忘；隔离扩展虽能避免干扰，但在长任务流上严重限制参数效率。为解决这一困境，我们提出CRAM。具体而言，通过将任务特定模式隔离到独立模块，CRAM缓解了跨任务的灾难性遗忘。为进一步提升参数效率，我们采用自适应秩实例化来识别现有专家能力与新任务需求之间的能力差距，并动态分配仅必要的参数。为确保任务间稳定重用，质心引导路由识别并激活现有专家的能力，而正交惩罚则将新更新限制在任务特定方向，防止重新学习通用能力。在多种基准上的广泛实验一致证明了其相对于现有方法的优越性。

## Abstract
Multimodal Large Language Models (MLLMs) unify heterogeneous vision-language tasks under a shared generative framework via instruction tuning, yet real-world deployment demands continuous capability expansion, making Multimodal Continual Instruction Tuning (MCIT) essential. Existing methods either update all tasks with a shared parameter set or allocate dedicated modules for each new task. Shared updates force heterogeneous tasks to compete, causing forgetting of learned capabilities. Conversely, isolated expansion prevents interference but severely limits parameter efficiency over long task streams. To address this dilemma, we propose CRAM. Specifically, by isolating task-specific patterns into independent modules, CRAM mitigates catastrophic forgetting across tasks. To further boost parameter efficiency, we utilize adaptive-rank instantiation to identify the capability gap between existing expert capability and new task demands, and dynamically allocate only the necessary parameters. To ensure stable reuse among tasks, centroid-guided routing recognizes and activates existing experts' capabilities, while an orthogonality penalty confines new updates to task-specific directions, preventing re-learning general capability. Extensive experiments across diverse benchmarks consistently demonstrate its superiority over existing methods.

### 2. 方法论：核心思想与关键技术
CRAM 由三个协同模块构成，整体遵循“先隔离格式冲突，再在组内安全复用并仅补足差距”的直觉。

- **语义分组路由（Semantic Group Routing）**  
  用冻结的 CLIP 文本编码器提取指令嵌入，通过余弦相似度与各簇中心的相对置信度（最高与次高相似度之差）进行动态分组。若差值超过阈值则归入最佳匹配组，否则创建新簇。分组中心随新样本平滑更新，从而将异构指令隔离在不同语义组内，避免梯度干扰。

- **自适应秩专家实例化（Adaptive‑Rank Expert Instantiation）**  
  1. **预热阶段**：在任务初期累积梯度至临时 LoRA 缓冲区 \(W_B\)，再对该缓冲区做奇异值分解（SVD），保留主方向。  
  2. **谱阈值过滤**：剔除奇异值过小（\(\sigma_p \le \tau_{\text{alloc}}\)）的噪声方向。  
  3. **历史子空间正交过滤**：将组内所有历史专家的降维矩阵 \(A_i\) 横向拼接得 \(M_{\text{hist}}\)，用 QR 分解提取正交基 \(Q\)，计算候选方向 \(v_p\) 在历史子空间补集上的能量占比 \(\alpha_p\)。仅保留 \(\alpha_p > \tau_{\text{orth}}\) 的方向，重构出新专家的 LoRA 矩阵 \(A_t, B_t\)。  
  该机制只为现有专家无法覆盖的能力差距分配参数，自然控制模型增长。

- **质心引导正交学习（Centroid‑Guided Orthogonal Learning）**  
  - 为每个专家分配一个可学习的质心向量 \(w_k\)，用预热阶段累积的视觉特征均值初始化。路由权重由高斯径向基核（RBF）计算：\(\rho(\xi_i, w_k) = \exp(-\|\xi_i - w_k\|_2^2 / 2\sigma^2)\)，并在组内归一化。任务结束后冻结质心，避免路由漂移。  
  - 同时引入正交惩罚损失 \(L_{\text{dec}} = \frac{1}{B}\sum_i \gamma_i \|\Delta W_{\text{new}}(QQ^\top h_i)\|_2^2\)，迫使新专家的更新仅作用于历史子空间的正交补方向，防止已有方向的重复强化和聚合失衡。

训练总损失为生成损失 \(L_{\text{NLL}}\) 与 \(L_{\text{dec}}\) 之和。推理时直接根据语义组和视觉亲和力路由即可。

  主要指标为所有任务学完后的平均最终准确率 \(\bar{A} = \frac{1}{T}\sum_{s} A_{s,T}\)。

### 6. 主要结论与发现
- CRAM 在 UCIT 和 TriGap 上均取得最高平均准确率（UCIT 74.73%，TriGap 47.79%），分别超越最强基线 SAME 与 DISCO，且**使用的参数量最少**。  
- 语义分组路由有效缓解指令格式引起的灾难性遗忘，自适应秩实例化通过正交过滤精准定位能力缺口，仅需少量参数即可覆盖新知识。  
- 质心引导路由和正交惩罚确保专家稳定激活、新学习不覆盖历史方向，实现高效的能力复用。  
- 该方法对任务顺序不敏感，且能提升对未见域的泛化能力（如 MMMU 上平均 +1.53%）。

### 8. 不足与局限
- **任务流长度有限**：文内坦承仅在最长 10 个任务的序列上验证，未测试更长任务流（如几十个任务），该方法在大规模流式学习下的扩展性尚需探索。  
- **分组依赖外部编码器**：语义分组使用了冻结的 CLIP 文本编码器，其嵌入质量可能影响分组效果；对于非自然语言指令或极端小众格式，分组鲁棒性有待检验。  
- **超参数敏感性**：虽然文中展示了几组超参数下波动不大，但实际部署时多个阈值（\(\theta, \sigma, \tau_{\text{alloc}}, \tau_{\text{orth}}\)）联合调优可能增加使用门槛。  
- **计算开销**：每次任务需进行 SVD 和 QR 分解，虽开销不大，但在极大规模模型或极频繁任务到来时仍可能成为瓶颈。
