## 摘要
智能体LLMs必须持续决定新提取的事实是应该被添加、与现有记忆合并还是忽略，但先前的工作更多关注检索和存储而非有原则的写入端控制。我们将记忆演化框架化为新颖性检测问题，并提出SAGE（Spherical Adaptive Gate for memory Evolution），它使用基于von Mises-Fisher的密度估计器在记忆嵌入上对候选事实评分，并通过跟踪记忆存储几何的自适应阈值进行路由。SAGE将明确新颖的事实归为ADD，明确冗余的事实归为NOOP，仅将不确定的情况发送到LLM合并步骤，从而减少昂贵的写入时推理。在LoCoMo上，SAGE在所有七个开源权重骨干模型的比较中，相对于Mem0取得了最佳平均token-F1分数，而在GPT-4o-mini上，它使添加阶段的API成本降低了3.4倍，延迟降低了2.5倍，仅伴有很小的平均评判分数差距。作为A-Mem的即插即用二元门控，SAGE在五个模型中跳过了大约16-18%的LLM调用，且在开源权重骨干上质量变化极小。这些结果表明，新颖性感知的写入控制是改善长期智能体记忆中记忆质量和系统效率的实用手段。

## Abstract
Agentic LLMs must continuously decide whether newly extracted facts should be added, merged with existing memories, or ignored, yet prior work has focused more on retrieval and storage than on principled write-side control. We frame memory evolution as a novelty-detection problem and propose SAGE, a Spherical Adaptive Gate for memory Evolution that scores candidate facts with a von Mises-Fisher-based density estimator over memory embeddings and routes them with an adaptive threshold that tracks memory-store geometry. SAGE resolves clearly novel facts as ADD, clearly redundant facts as NOOP, and sends only uncertain cases to an LLM merge step, reducing expensive write-time reasoning. On LoCoMo, SAGE achieves the best average token-F1 against Mem0 on all seven open-weight backbone comparisons, while on GPT-4o-mini it reduces add-phase API cost by 3.4$\times$ and add-phase latency by 2.5$\times$ with only a small average judge-score gap. As a drop-in binary gate for A-Mem, SAGE skips roughly 16-18% of LLM calls across five models with minimal quality change on open-weight backbones. These results suggest that novelty-aware write control is a practical lever for improving both memory quality and system efficiency in long-term agentic memory.

## 1. 论文的核心问题与整体含义

- **背景与动机**：在智能体 LLM（Agentic LLM）构建长期记忆系统时，现有工作大量投入在检索与存储技术上，而对“写入端控制”（即决定哪些新事实应被写入、合并或丢弃）缺少有原则的研究。
- **核心问题**：智能体需要在多轮对话中持续更新自身记忆，但若将每一个新提取的事实都交给 LLM 判断是否写入（如 Mem0、A-Mem 的做法），会造成大量冗余计算和高昂成本；而简单的启发式写入策略又可能丢失信息或造成记忆污染。
- **整体含义**：论文将记忆演化重新定义为新颖性检测问题——先判断候选事实相对于当前记忆库是否“足够新”，再决定 ADD/UPDATE/NOOP。由此提出一种廉价的、闭环形式的门控器 SAGE，仅让少量不确定的事实触发 LLM 合并，从而在维持甚至提升记忆质量的同时大幅降低写入成本。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：通过在单位超球面上的密度估计，量化候选事实的“新颖性”，并以记忆库的几何密度自适应地设定决策阈值。
- **关键技术细节**：
  - **嵌入与归一化**：所有记忆项和候选事实均用句子嵌入模型得到向量，并 ℓ2 归一化到单位超球面 \( \mathbb{S}^{d-1} \)。
  - **vMF 核密度估计**：对候选事实 c 与记忆库 \( \mathcal{M} \) 使用 von Mises-Fisher 核 \( K_\kappa(c, m_i) = \exp(\kappa m_i^\top c) \)，计算平均密度 \(\hat{S}(c|\mathcal{M}) = \frac{1}{N} \sum_{i=1}^{N} K_\kappa(c,m_i)\)。
  - **新颖性得分**：定义 \(s_{\text{vMF}}(c|\mathcal{M}) = \frac{1}{\kappa}\log \hat{S}(c|\mathcal{M})\)，再变换为新颖性得分 \( \nu(c) = 1 - s_{\text{vMF}}(c|\mathcal{M})^2 \)，值越大表示越新颖。该得分考虑了全部记忆项的方向支持，而非仅依赖最近邻的余弦相似度。
  - **浓度参数 κ 的自适应估计**：根据记忆向量的平均合向量长度 \(\bar{R}\) 用 Banerjee et al. 的近似公式 \(\hat{\kappa} \approx \frac{\bar{R}(d - \bar{R}^2)}{1 - \bar{R}^2}\)，使核的带宽随记忆库稀疏度自动调整。
  - **自适应阈值与路由规则**：
    - 用 PCA 降维后的体积密度代理 \( \rho_t = N_t / V_t \) 量化记忆库拥挤程度。
    - 阈值按 \( \tau_t^\star = \tau_{\min} + \tau_0 e^{-\lambda \rho_t} \) 衰减，并通过 EMA 平滑得到 \( \tau_t \)（避免突变）。
    - 设置不确定带宽度 δ，路由决策为：
      - \( \nu(c) \ge \tau_t + \delta \) → ADD（无需 LLM）
      - \( \tau_t \le \nu(c) < \tau_t + \delta \) → UPDATE（唯一触发 LLM 合并）
      - \( \nu(c) < \tau_t \) → NOOP（无需 LLM）
    - 参数（\( \tau_0=0.25, \tau_{\min}=0.025, \lambda=2.0, \alpha=0.9, \delta=0.025 \)）在 20% LoCoMo 子集上选定，所有骨干模型共用。
  - **作为即插即用二元 NOOP 门控**：设定固定阈值 \( \tau_{\text{noop}} \)，若 \( s_{\text{vMF}}(c|\mathcal{M}) > \tau_{\text{noop}} \) 则直接 NOOP，否则将事实原样传入宿主系统（如 A-Mem）。\( \tau_{\text{noop}} \) 通过合成数据离线校准至与真实对话记忆分布匹配的 80% 分位点，未接触测试集。

## 6. 主要结论与发现

- **质量与效率双赢**：SAGE 在 7/7 开源骨干上取得平均 token-F1 第一，同时在 GPT-4o-mini 上将添加阶段 API 成本降低 **3.4×**，延迟降低 **2.5×**，而平均 Judge 分数仅下降 1.3 点。
- **新颖性门控有效取代大量 LLM 路由**：SAGE 在写入阶段零 LLM 路由调用，仅需对约 2.7%~10.6% 的不确定事实触发 LLM 合并；总写入 LLM 调用减少 29%~42%（平均 32%）。
- **自适应阈值优于固定阈值**：自适应阈值在不同密度下自动调整，避免固定阈值随记忆增长而过于保守或激进；消融表明其鲁棒性优于任何单一固定值。
- **即插即用的 NOOP 门控几乎无损**：在 A-Mem 前插入 SAGE 二元门控，可跳过 15.8%~17.9% 的写入调用，开源模型上 Judge 分数变化 ≤ 0.65%，GPT-4o-mini 上下降 2.01%，整体代价极小。

- **记忆演化的新颖性抽象具有普适意义**：将写入控制抽象为新颖性检测，为未来记忆压缩、删除策略提供了可行的几何基础。

## 7. 优点

- **创新性强**：首次将记忆写入控制系统地形式化为新颖性检测，并在球面几何中给出封闭解，区别于完全依赖 LLM 决策或强化学习的昂贵方案。
- **理论与工程结合紧密**：vMF 密度估计与自适应阈值均有数学支撑，且参数经少量数据选定后跨模型泛化良好，无需训练或按骨干调优。
- **即插即用与低侵入性**：二元 NOOP 门控仅需设定一个阈值即可嵌入现有系统，无需修改记忆内部逻辑，校准方法也避免了测试集泄露。
- **高效且可扩展**：几乎不增加额外计算（闭合形式向量运算），在 GPT-4o-mini 等实际 API 应用中可成倍节省费用和延迟，对部署友好。
- **实验详尽扎实**：覆盖多种模型规模、多个任务类别，对效率指标（调用次数、token 数、延迟、成本）进行了全面测量，消融和隔离实验充分。

## 8. 不足与局限

- **单一数据集与语言**：仅在英文 LoCoMo 对话记忆基准上评估，未在 LongMemEval 等更具挑战性的基准或多语言场景下验证。
- **功能覆盖不全**：当前 SAGE 仅支持 ADD/UPDATE/NOOP 路由，未涉及 DELETE 决策，也未提供记忆压缩或遗忘机制。
- **依赖嵌入模型质量**：新颖性得分基于 ℓ2 归一化的句子嵌入，语义上不同但向量相似的事实可能被误删，而相同语义的改写可能因向量差异较大而绕过冗余过滤。
- **自适应阈值参数仍基于少量数据选择**：虽然选定后固定，但 δ、λ 等超参数对小样本的敏感性未进行彻底分析，可能仍需针对新场景微调。
- **缺乏与强化学习方法的直接对比**：论文对比了 Mem0 和 Mem0g，但与 Memory-R1、Mem-α 等基于 RL 的写控制方法未做比较，对高效训练式方案的相对性价比未阐明。
- **GPT-4o-mini 上 Temporal 类问题出现较大质量下降**：Judge 分数差 7.3 点，显示在强模型下门控对时序相关事实的处理可能不足，需进一步优化。
