## 摘要
动态环境中的终身具身导航要求机器人从零散的观察中形成持久的场景理解，这对于依赖显式地图或场景图且难以泛化到结构化环境之外的现有方法来说仍然困难。我们提出了AllDayNav，一个终身自学习导航框架，通过强化学习将场景动态隐式编码到具有十亿规模参数的大模型中，并由一个自我演化的多模态记忆驱动，该记忆维护和更新视觉关键帧、语义描述和时间上下文，同时自主生成开放词汇指令、图像目标和结构化奖励。在合成环境和真实世界环境中跨房间、跨片段和跨任务场景的实验表明，AllDayNav的成功率接近100%，在路径效率和鲁棒性方面始终超越强大的基于地图、VLM和RL的基线模型，证明了隐式、记忆驱动的强化学习作为显式建图的可扩展替代方案，能够实现可靠的终身导航。

## Abstract
Lifelong embodied navigation in dynamic environments requires robots to form persistent scene understanding from fragmentary observations, which remains difficult for existing methods that rely on explicit maps or scene graphs and struggle to generalize beyond structured settings. We propose AllDayNav, a lifelong self-learning navigation framework that implicitly encodes scene dynamics into the billion-scale parameters of a large model via reinforcement learning, powered by a self-evolving multimodal memory that maintains and updates visual keyframes, semantic descriptions, and temporal context while autonomously generating open-vocabulary instructions, image goals, and structured rewards. Experiments in both synthetic and real-world environments across cross-room, cross-episode, and cross-task scenarios show that AllDayNav achieves success rates approaching $100\%$ and consistently surpasses strong map-based, VLM, and RL baselines in path efficiency and robustness, demonstrating implicit, memory-driven reinforcement learning as a scalable alternative to explicit mapping for reliable lifelong navigation.

### 2. 方法论
AllDayNav 的核心是一个闭环的 **“记忆-策略”共进化（Memory-Policy Co-evolution）** 系统，包含四大部分：

- **预训练VLA导航骨干网络**：
  - **双路视觉编码**：每个RGB帧用 SigLIP（语义）和 DINOv2（结构）提取特征，然后拼接并经过MLP投影送到Transformer（Qwen2-7B）。
  - **历史压缩与注意力偏置**：当前帧和目标帧保留全分辨率token（64个），历史帧经全局平均池化压缩为4个token，并施加指数衰减的注意力偏置，以平衡计算效率和长时上下文。
  - **动作表示**：模型预测连续路径点序列（8个未来waypoints的偏移量和朝向），便于平滑执行。
  - **预训练**：在Habitat模拟器中用HM3D和MP3D的大规模图像目标导航数据进行行为克隆（MSE损失），并配合强数据增强（运动模糊、颜色抖动、遮挡等）以实现Sim-to-Real迁移。

- **自演化多模态记忆数据库（Self-Evolving Multimodal Memory）**：
  - **记忆条目**：每个记忆包含RGB关键帧、VLM生成的语义描述、时间戳和预计算的LLaVE视觉嵌入。
  - **自主构建与更新**：探索过程中，根据当前帧与上一关键帧的嵌入相似度筛选待选帧。对于候选帧，检查与全库条目的最大相似度；若足够新颖则添加，若重叠但新帧能更好地匹配描述则替换旧帧，从而保持记忆的多样性和代表性。
  - **语义检索**：对于用户指令，直接使用VLM（Qwen3-VL-8B）从记忆的描述和时间戳集合中选择最匹配的条目，并返回对应目标图像和置信度。

- **自指令生成与混合目标检索**：
  - **自指令生成**：定期（每10个片段或记忆增长20%）从记忆中聚合所有语义描述，由VLM生成50条多样化的导航指令（涵盖物体、功能、空间、组合和时间指令），以此构建自我驱动的课程学习。
  - **混合目标检索**：对每条指令，优先从记忆检索目标图像；若检索置信度低于阈值，或早期记忆稀疏时，则依概率回退到互联网图像数据库，确保训练信号持续，并驱动探索未知区域。

- **保守Q学习（CQL）终身策略优化**：
  - **MDP与奖励函数**：导航任务建模为无限期MDP。奖励包含终止奖励（当停留且视觉相似度≥0.75时+10）、进度奖励（首次跨过0.5、0.6、0.7相似度时+2）、时间惩罚（-0.01/步）和碰撞惩罚（-0.1）。视觉相似度用LLaVE嵌入的余弦相似度计算，且异步计算以避免阻塞控制回路。
  - **CQL目标**：训练单独的critic网络，在Bellman误差之外，增加保守正则项（惩罚分布外动作的高Q值），防止过估计。策略更新则结合Q值最大化和行为克隆损失（仅对成功轨迹），其中BC损失作为稳定器。
  - **在线采集**：探索片段使用当前策略和自生成任务对填充回放缓冲区，同时更新记忆，形成闭环（算法1）。
