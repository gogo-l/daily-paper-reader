## 摘要
联邦持续学习（FCL）必须在通信、计算、内存和标签可用性等有限资源下，从分布式任务流中学习。现有 FCL 方法通常依赖重复的本地优化、回放和全监督。解析替代方案避免了迭代训练和回放，但为了提升精度而使用高维随机特征需要一个二阶特征统计量——格拉姆矩阵，其通信开销与随机特征大小 M 呈二次方关系。我们提出 FedRAN，一种资源感知的解析 FCL 框架，用紧凑的随机特征统计量替代基于梯度的更新。每个客户端传输其格拉姆矩阵的截断 SVD 摘要，将主要的二阶上传量从 O(M^2) 降至固定秩下的 O(M)。服务器执行两级 QR-SVD 子空间合并，在空间上跨客户端、时间上跨任务，并求解封闭形式的岭回归分类器。FedRAN 进一步通过基于原型的伪标记支持标签稀缺场景。在 CIFAR-100、ImageNet-R 和 VTAB 数据集上，FedRAN 相较最强基线平均准确率提升高达 4.8 个百分点，单客户端通信量比基于优化的 FCL 少 30.6–121.8 倍，平均比基于梯度的基线快 190.3 倍；在仅 20% 标签时，伪标记使平均准确率提升高达 6.61 个百分点。这些结果表明，FedRAN 能够在通信、计算和标签约束下实现准确且资源高效的联邦持续学习。源代码见 https://github.com/JebacyrilArockiaraj/Fed-RAN-SSL。

## Abstract
Federated continual learning (FCL) must learn from distributed task streams under limited resources, such as communication, computation, memory, and label availability. Existing FCL methods often rely on repeated local optimization, replay, and full supervision. Analytic alternatives avoid iterative training and replay, but using high-dimensional random features to improve accuracy requires a second-order feature statistic, the Gram matrix, which has a quadratic communication cost in the random feature size $M$. We propose FedRAN, a resource-aware analytic FCL framework that replaces gradient-based updates with compact random feature statistics. Each client transmits a truncated-SVD summary of its Gram matrix, reducing the dominant second-order upload from quadratic to linear in $M$ for fixed rank. The server performs a two-level QR-SVD subspace merge, spatially across clients and temporally across tasks, and solves a ridge classifier in closed form. FedRAN further supports label scarcity through prototype-based pseudo-labeling. Across CIFAR-100, ImageNet-R, and VTAB datasets, FedRAN improves average accuracy by up to 4.8 percentage points over the strongest baseline, uses 30.6-121.8$\times$ less per-client communication than optimization-based FCL, and is 190.3$\times$ faster on average than gradient-based baselines; with only 20% labels, pseudo-labeling improves average accuracy by up to 6.61 points. These results show that FedRAN enables accurate and resource-efficient FCL under communication, computation, and label constraints. The source code is available at https://github.com/JebacyrilArockiaraj/Fed-RAN-SSL.

        *   **基于解析的方法**：这些方法通过冻结特征提取器，以封闭形式更新分类器，避免了迭代训练。然而，为了提升精度而引入高维随机特征时，必要的二阶统计量（格拉姆矩阵）的通信成本随随机特征维度M呈\(O(M^2)\)增长，成为新的通信瓶颈。仅使用一阶统计量估计二阶信息又会损失精度。
*   **整体含义**：本研究旨在填补现有方法的空白，设计一个能在精度与资源（通信、计算、标签）效率之间取得最佳平衡的联邦持续学习框架。

### 2. 方法论：FedRAN框架

FedRAN是一个资源感知的解析式联邦持续学习框架，其核心思想是用紧凑的统计数据通信取代迭代的模型梯度更新。

*   **核心思想**：
    1.  **特征提取固定化**：所有客户端共享一个冻结的预训练模型作为特征提取器，从而避免客户端更新导致的特征漂移，并消除昂贵的反向传播计算。
    2.  **通信统计量化**：客户端不再传输模型参数或完整的二阶格拉姆矩阵，而是上传两个紧凑的统计量。
    3.  **服务器解析更新**：服务器以封闭形式（解析解）合并统计量并更新全局分类器，无需迭代训练。

*   **关键技术细节与流程**：
    1.  **客户端：特征提取与随机投影**：
        *   客户端对本地数据使用冻结的预训练模型\(f(\cdot)\)提取特征\(Z_{k,t}\)。
        *   应用一个固定的、共享的随机投影矩阵\(P\)和ReLU激活函数，将特征映射到高维随机特征空间：\(H_{k,t} = \text{ReLU}(Z_{k,t} P)\)。这使特征更具线性可分性，利于后续的解析分类器。
    2.  **客户端：低秩统计摘要生成**：
        *   **截断SVD**：为了解决完整格拉姆矩阵\(G_{k,t} = H_{k,t}^T H_{k,t}\)上传成本\(O(M^2)\)过高的问题，客户端计算随机特征矩阵\(H_{k,t}\)的截断SVD，得到一个秩为\(r\)的近似：\(H_{k,t} \approx V_{k,t} \text{diag}(\sigma_{k,t}) V_{k,t}^T\)。
        *   **上传内容**：客户端仅上传低秩因子\((V_{k,t}, \sigma_{k,t})\)（成本降为\(O(Mr)\)）和精确的标签-特征统计量\(B_{k,t} = H_{k,t}^T Y_{k,t}\)。
    3.  **服务器：两级QR-SVD子空间合并**：
        *   **空间合并**：服务器对当前任务中来自不同客户端的低秩摘要\((V, \sigma)\)进行QR-SVD合并，生成该任务的全局摘要。
        *   **时间合并**：将当前任务的全局摘要与历史任务的累积全局摘要再次进行QR-SVD合并。
        *   **合并操作**：对于两组摘要\((V_a, \sigma_a)\)和\((V_b, \sigma_b)\)，合并过程为：首先形成拼接矩阵 \(A = [V_a \text{diag}(\sigma_a), V_b \text{diag}(\sigma_b)]\)，然后计算\(A = QR\)，最后对矩阵\(R\)进行SVD并截断至目标秩\(r\)。该操作避免了显式构建\(M \times M\)矩阵。
    4.  **服务器：解析分类器更新**：
        *   服务器利用合并后的全局低秩摘要\((V_{1:t}, \sigma_{1:t})\)和累积的精确标签-特征统计量\(B_{1:t}\)，在保留的子空间内求解岭回归问题。
        *   分类器权重矩阵通过闭式解计算：\(\widetilde{W}_{1:t} = (\text{diag}(\sigma_{1:t}^2) + \lambda I)^{-1} V_{1:t}^T B_{1:t}\)， \(W_{1:t} = V_{1:t} \widetilde{W}_{1:t}\)。这避免了高维矩阵求逆。
    5.  **标签稀缺应对：原型伪标记 (FedRAN-SSL)**：
        *   客户端为每个有标签的类别计算原型（特征均值）。
        *   对于无标签样本，计算其与各原型的余弦相似度，若最高相似度超过阈值\(\tau\)，则为其分配伪标签。
        *   被接受的伪标签样本及其特征将被用于计算标签-特征统计量\(B_{k,t}\)，从而利用无标签数据提升模型性能。
