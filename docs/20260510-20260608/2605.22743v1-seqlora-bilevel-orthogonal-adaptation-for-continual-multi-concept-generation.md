## 摘要
参数高效微调能够快速个性化文本到图像扩散模型，但组合多个自定义概念仍因表征干扰而具有挑战性。现有模块化方法要么依赖昂贵的后融合，要么冻结适配子空间，限制了表达能力和概念保真度。为解决这一权衡问题，我们提出了序贯正则化LoRA（SeqLoRA），这是一个通过双层优化联合优化两个LoRA因子的约束持续学习框架。理论上，我们为算法建立了强收敛保证，并将残差层激活建模为矩阵亚高斯过程，从而推导出灾难性遗忘的高概率界。我们进一步证明，从数据中学习LoRA基比冻结基方法能更有效地最小化残差干扰能量。在多概念图像生成实验上，SeqLoRA在多达101个概念上改善了身份保持和扩展性，同时避免了昂贵的融合，并减少了组合生成中的属性干扰。

## Abstract
Parameter-efficient fine-tuning enables fast personalization of text-to-image diffusion models, but composing multiple custom concepts remains challenging due to representation interference. Existing modular methods either rely on expensive post-hoc fusion or freeze adaptation subspaces, which limit expressiveness and concept fidelity. To address this trade-off, we propose Sequential regularized LoRA (SeqLoRA), a constrained continual learning framework that jointly optimizes both LoRA factors via bilevel optimization. Theoretically, we establish strong convergence guarantees for our algorithm and model the residual layer activations as a matrix sub-Gaussian process to derive high-probability bounds on catastrophic forgetting. We further prove that learning the LoRA basis from data minimizes residual interference energy more effectively than frozen-basis methods. Experiments on multi-concept image generation demonstrate that SeqLoRA improves identity preservation and scalability across up to 101 concepts, while avoiding costly fusion and reducing attribute interference in composed generations.

文本到图像扩散模型（如 Stable Diffusion）通过参数高效微调（特别是 LoRA）可快速个性化生成单个概念，但组合多个已学习的自定义概念生成图像时，面临严重的表示干扰问题。由于不同概念的 LoRA 适配残差在参数空间中高度相关，简单地将它们叠加会导致属性纠缠、身份混淆甚至生成失败。

现有解决方案存在表达力–正交性权衡：联合训练要求同时访问所有数据，不可扩展且存在隐私问题；梯度融合方法需对每个概念组合重新优化，缺乏真正的模块化能力；冻结 LoRA 基的模块化方法则牺牲了保真度。因此，论文核心在于解决持续学习场景下多概念组合生成中的灾难性遗忘与表示干扰问题，同时保持概念的独立保真度和即插即用的模块化组合能力。

### 2. 论文提出的方法论
论文提出了 **SeqLoRA**（序贯正则化 LoRA），将多概念生成形式化为带约束的连续优化问题。核心思想是顺序学习每个概念时，强制新概念的 LoRA 右因子 \(B_i\) 与先前所有概念的 \(B_{j<i}\) 精确正交（\(B_j^\top B_i = 0,\ \forall j<i\)），同时通过双层优化联合学习左右因子 \((A_i, B_i)\)，而非冻结基。

**关键技术细节与流程：**
*   **约束优化目标：**
    \[
    \min_{A_i, B_i \in \mathcal{B}_i} \mathcal{L}_i(A_i, B_i)
    \]
    其中 \(\mathcal{B}_i = \{B_i \in \mathbb{R}^{m \times r} \mid B_j^\top B_i = 0,\ \forall j < i\}\)。
*   **双层优化分解：** 将原问题重写为
    \[
    \min_{B_i \in \mathcal{B}_i} \mathcal{L}_i(A_i^*(B_i), B_i) \quad \text{s.t.} \quad A_i^*(B_i) = \arg\min_{A_i} \mathcal{L}_i(A_i, B_i)
    \]
    上层优化 \(B_i\)，下层求解当前 \(B_i\) 下的最优 \(A_i\)。下层采用一步二次近似更新 \(A_i^{(k+1)}(B_i) = A_i^{(k)} - \alpha \nabla_{A_i}\mathcal{L}_i\)。
*   **交叉海森修正：** 上层计算简化目标 \(\Phi_i(B_i)\) 的梯度时，不仅包含直接偏导 \(\nabla_{B_i}\mathcal{L}_i\)，还通过**自动微分计算交叉海森** \(\nabla_{B_i A_i}^2 \mathcal{L}_i\) 捕获下层 \(A_i\) 的隐式依赖，获得更丰富的下降方向。
*   **闭式正交投影：** 上层对 \(\Phi_i(B_i)\) 构建二次模型，在正交约束集 \(\mathcal{B}_i\) 上最小化等价于将无约束步 \(\tilde{B}_i\) 投影到已学习基的零空间：
    \[
    B_i^{(k+1)} = \left[I - B_{\text{int}}(B_{\text{int}}^\top B_{\text{int}})^{-1}B_{\text{int}}^\top\right] \tilde{B}_i
    \]
    其中 \(B_{\text{int}}\) 是先前所有概念的基按列拼接构成。算法交替进行下层 A 更新与上层 B 投影迭代直至收敛。

**理论贡献：**
1.  **收敛性保证：** 证明在合适步长下算法单调递减并收敛至原约束问题的临界点。
2.  **遗忘上界：** 将深度网络残差激活建模为矩阵亚高斯过程，推导灾难性遗忘的高概率界：
    \[
    \mathcal{L}_j(\theta_T) - \mathcal{L}_j(\theta_j) \le L_o \sum_{\ell=1}^L \Gamma_\ell \left( \sqrt{\text{Tr}(\Psi_j^{(\ell)})\|Q_j^{(\ell)}\|_F^2} + t^{(\ell)} \right)
    \]
    指出遗忘由残差协方差 \(\Sigma_{j}^{\perp}\) 控制。
3.  **基最优性证明：** 证明在可行正交补空间中，最小化残留干扰等价于让 \(B_j\) 张成输入激活的 Top-r 主成分空间，因此从数据学习基严格优于随机冻结基（除非残差空间各向同性）。

### 3. 实验设计
实验旨在验证 SeqLoRA 的身份保持、可扩展性、组合能力以及与基线的对比。
*   **数据集 / 场景：** 使用 **CustomConcept101 数据集**，涵盖不同数量的多概念生成任务（8、16、32、40、48、64、80、101 个概念）。

*   **评估指标：**
    *   **身份保持 / 相似度：** DINO, DINOv2, DINOv3, DreamSim, CLIP-I。

*   **对比方法：**
    *   **Continual Alternating：** 消融基线，标准的冻结 A 更新 B、冻结 B 更新 A 的交替最小化（无交叉海森修正）。
    *   **Mix-of-Show：** 代表基于优化的后融合方法。
    *   **Orthogonal Adaptation：** 代表冻结随机正交基的模块化方法。

### 4. 资源与算力
*   **硬件：** 所有实验均使用 **2× NVIDIA A100 GPU**。

### 7. 优点
*   **创新的优化框架：** 巧妙地将多概念 LoRA 适配重构为具有闭式正交投影的双层优化问题，首次在模块化持续学习中实现了双因子联合学习。
*   **坚实的理论贡献：** 提供了非凸约束优化的收敛证明和基于 Hanson-Wright 不等式的灾难性遗忘高概率界，理论深度显著优于同类工作。

*   **洞察深刻：** 揭示并严格证明了“学习 LoRA 基”相较于“冻结随机基”在统计上的绝对优势，为后续工作提供了重要依据。

### 8. 不足与局限
*   **计算开销相对较高：** 双层优化中的交叉海森计算带来了额外的训练时间成本，尽管通过减少总迭代数和免除后融合时间进行了摊销，但单卡或小规模资源下的训练速度仍慢于简单的正交适配方法。
*   **容量硬限制：** 线性正交约束使每层最大可学习概念数受限于 \(m/r\)。虽然对典型层（m=768, r=4, 上限 192）在当前实验中未触及瓶颈，但未来若使用更低秩或更高概念数的极限场景下可能受限。
*   **理论假设条件：** 理论结果依赖于损失函数的平滑、梯度有界等标准假设，以及将残差激活建模为亚高斯过程，这些是合理但理想化的条件。
*   **基础模型单一：** 实验仅基于 Stable Diffusion v1.5，未在更新、更先进的扩散模型架构（如 SDXL, FLUX 等）上验证其泛化性。
*   **概念顺序影响未探索：** 持续学习通常对任务顺序敏感，论文未开展概念训练顺序对最终性能影响的稳健性研究。
