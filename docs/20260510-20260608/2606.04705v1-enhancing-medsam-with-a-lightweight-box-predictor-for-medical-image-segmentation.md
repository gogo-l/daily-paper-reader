## 摘要
医学影像中的语义分割是一项关键但具有挑战性的任务，原因是数据稀缺且不同模态之间存在高度变异性。尽管像Segment Anything Model (SAM)这样的基础模型显示出潜力，但如果没有针对性的适配，它们常常难以处理医学图像。此外，点提示虽然是最自然的用户交互形式，却无法为可靠分割提供足够的空间上下文，尤其当目标结构不规则或对比度差时。在本文中，我们提出了一种增强的分割框架，将轻量级边框预测器模块集成到MedSAM架构中。该边框预测器利用局部图像嵌入特征从单次用户点击中估计出一个近似边界框，提供空间引导以减少点提示的歧义，同时仅增加了160万个参数和可忽略不计的推理开销。我们引入了一个两阶段训练流程，其中边框预测器在集成到MedSAM之前先独立训练。为了验证我们方法的泛化能力，我们在四个不同的数据集（FLARE22、BRISC、BUSI、LungSegDB）上进行了广泛评估，这些数据集涵盖了不同的成像模态，包括CT、MRI和超声。我们的方法提高了在不同解剖结构和成像域上的分割准确性和鲁棒性，在BUSI上达到0.89的Dice分数，FLARE22上0.93，BRISC上0.88，LungSegDB上0.98。代码可在https://github.com/Amirhosseinmovahedi/MedSAM-BoxPredictor获取。

## Abstract
Semantic segmentation in medical imaging is a critical yet challenging task due to data scarcity and high variability across modalities. While foundation models like the Segment Anything Model (SAM) show promise, they often struggle with medical images without specific adaptation. Moreover, point prompts, despite being the most natural form of user interaction, provide insufficient spatial context for reliable segmentation, particularly when target structures are irregular or poorly contrasted. In this paper, we propose an enhanced segmentation framework that integrates a lightweight Box Predictor module into the MedSAM architecture. The Box Predictor estimates an approximate bounding box from a single user click using localized image embedding features, providing spatial guidance that reduces the ambiguity of point prompts, while introducing only 1.6M additional parameters and negligible inference overhead. We introduce a two-stage training pipeline where the Box Predictor is trained independently before being integrated into MedSAM. To validate the generalization capability of our method, we conduct extensive evaluations on four diverse datasets (FLARE22, BRISC, BUSI, LungSegDB) spanning distinct imaging modalities, including CT, MRI, and Ultrasound. Our method improves segmentation accuracy and robustness across varied anatomical structures and imaging domains, achieving Dice scores of 0.89 (BUSI), 0.93 (FLARE22), 0.88 (BRISC), and 0.98 (LungSegDB). Code is available at https://github.com/Amirhosseinmovahedi/MedSAM-BoxPredictor

### 2. 论文提出的方法论

- **核心思想**  
  - **两阶段训练 + 轻量级 Box Predictor 模块**  
  - 第一阶段：**独立训练**一个由多层感知器（MLP）构成的 Box Predictor，从单一点击附近的局部图像嵌入特征直接预测目标区域的近似边界框（box）。  
  - 第二阶段：将**冻结**的 Box Predictor 和 Image Encoder 与 MedSAM 的 Prompt Encoder 和 Mask Decoder 结合，后者可选择**冻结或微调**，从而在极低参数增量下引入空间先验。

- **关键技术细节与流程**  
  - **输入点生成**（模拟临床点击）  
    - 以真实掩膜质心为基准，施加均匀随机扰动 Δx, Δy，扰动范围 p 与**数据集平均掩膜面积的 30%** 对应：  
      p = ½ √(0.3 · A̅)  
    - 若扰动后点落在掩膜外，则重新采样至有效区域内，保证训练稳定。
  - **图像特征提取**  
    - 输入图像（1024×1024）经冻结的 Image Encoder 得到 64×64×256 的嵌入张量 F。
  - **Box Predictor 结构**  
    - 以点提示为中心，从 F 中裁取 5×5 局部块并展平为特征向量。  
    - MLP 结构：全连接层 ×3（256→128→4），输出 Δx, Δy, W, H。W、H 经 Softplus 保证非负，最终生成归一化框 [xmin, ymin, xmax, ymax]。  
    - 总参数量：约 **1.6M**。
  - **两阶段训练策略**  
    - **阶段一（Box Predictor 训练）**：图像编码器冻结，仅训练 Box Predictor。  
      - 损失函数：**L = L₁ + L_GIoU**  
        - L₁：预测框与真值框的坐标绝对误差。  
        - L_GIoU = 1 − GIoU，GIoU 在无重叠时仍能提供空间对齐梯度，互补于 L₁ 的坐标精度。  
    - **阶段二（MedSAM 分割训练）**：Box Predictor 和 Image Encoder 冻结，Prompt Encoder 和 Mask Decoder 可训练（或冻结）。  
      - 将预测框（可单独使用，也可与原点提示结合）输入 Prompt Encoder，生成嵌入 EP。  
      - Mask Decoder 融合图像特征 F 与 EP 预测最终掩膜 M。  
      - 分割损失：**L_total = L_Dice + L_BCE**，结合区域重叠与像素级二分类精度。

### 6. 论文的主要结论与发现

- **整体结论**  
  - 仅通过添加一个 **1.6M 参数**的轻量边框预测器，即可大幅提升 MedSAM 在**仅有点点击**下的分割准确性和稳定性，即使在 **MedSAM 完全冻结**时也能恢复有效分割。  
- **关键发现**  
  - **空间先验恢复是最强收益来源**：MedSAM 在冻结时对点提示几乎完全失效（Dice 低至 ~1%），因为其微调阶段主要接触的是框提示；预测框重新建立了几何条件，使 Dice 在四个数据集上恢复至 72%–89%。  
  - **预测框质量不必极高**，只要提供大致几何范围，就足以引导解码器生成精确掩膜。  
  - **点扰动鲁棒性**：30% 掩膜面积范围内的随机点击几乎不降低 Dice，模型在极端边界点击下仍可将性能维持在可用水平。  
  - **模态差异敏感度**：低对比度模态（超声、MRI）可从 10%–20% 框放大中获益；CT 模态初始预测框已接近最优。  
  - **提示组合策略**：冻结时“仅框”优于“框+点”；微调时二者收益相当，但框提示仍能在复杂数据集上带来稳健增益。  
  - **与自动分割的对比**：在目标多样、背景复杂的多器官 CT 上，纯自动方法极易失效，进一步凸显了交互式预测框引导的价值。

### 7. 优点

- **系统性的实验评估**：  
  - 涵盖四模态、多解剖结构、多方法对比、多角度消融（块尺寸、框大小、点击偏差），证据支撑扎实。

### 8. 不足与局限

- **单一目标假设**：  
  - 单点生成单框的方式**无法同时覆盖多个分散或不相连的目标区域**（如多发性病灶）。当需一次分割多个独立结构时会出现根本性短板。  
- **极限案例误差**：  
  - 在极小病灶（容易过估计）与多叶形高对比度病变（矩形先验反而导致欠分割）时，预测框可能降低精度，甚至弱于纯点提示。  
- **模态饱和效应**：  
  - 在 LungSegDB 这类结构标准、边界极度清晰的数据集上，增益幅度微小（接近性能天花板），区分度不强。  
- **训练阶段分离的潜在局限**：  
  - 两阶段独立训练可能导致 Box Predictor 生成的框并未针对最终分割目标进行最优协同，更多是恢复先验条件而非端到端联合优化。  
- **对点输入的依赖性**：  
  - 虽已对点击误差鲁棒，但整个框架**本质上仍然需要人工提供一个大体位置**，无法在零提示条件下工作。  
- **未涉及纵向/体积分割**：  
  - 全部分析基于 2D 切片，未评估其在 3D 体积或视频帧连续性（如 SAM2 的记忆机制）下的表现，限制了向真实临床三维工作流的迁移。
