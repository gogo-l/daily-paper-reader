## 摘要
跨域少样本医学图像分割（CD-FSMIS）要求模型仅从少量标注样本中同时泛化到新的解剖类别和未见过的成像域。现有的原型方法不可避免地将解剖结构与域特定的外观变化纠缠在一起，因此在域偏移下缺乏稳定的参考以实现可靠匹配。我们观察到，人体解剖的几何结构构成了一种可靠的、可跨域迁移的先验，而这一点一直被忽视。基于这一见解，我们提出了GeoProto，一个几何感知的CD-FSMIS框架，通过显式的结构先验丰富原型匹配。其核心组件几何感知原型增强（GAPE）为每个局部外观原型增加了一个学习到的几何偏移，该偏移编码了其在器官内部拓扑中的序数位置。该偏移源自一个辅助的序数形状分支（OSB），该分支在序数一致性目标下训练，强制几何嵌入在内部各层间单调变化，且除标准分割掩码外无需额外标注。在七个数据集上跨越三种评估设置（跨模态、跨序列和跨语境）的广泛实验表明，GeoProto实现了最先进的性能。

## Abstract
Cross-domain few-shot medical image segmentation (CD-FSMIS) requires a model to generalise simultaneously to novel anatomical categories and unseen imaging domains from only a handful of annotated examples. Existing prototypical approaches inevitably entangle anatomical structure with domain-specific appearance variations, and thus lack a stable reference for reliable matching under domain shift. We observe that the geometric structure of human anatomy constitutes a reliable, domain-transferable prior that has been overlooked. Building on this insight, we propose GeoProto, a geometry-aware CD-FSMIS framework that enriches prototypical matching with explicit structural priors. The core component, Geometry-Aware Prototype Enrichment (GAPE), augments each local appearance prototype with a learned geometric offset encoding its ordinal position within the organ's interior topology. This offset is derived from an auxiliary Ordinal Shape Branch (OSB) trained under an ordinally consistent objective that enforces monotonic variation of geometric embeddings across interior strata, requiring no annotation beyond standard segmentation masks. Extensive experiments across seven datasets spanning three evaluation settings (cross-modality, cross-sequence, and cross-context) demonstrate that GeoProto achieves state-of-the-art performance.

### 2. 方法论
方法核心 **GeoProto** 由两个关键组件构成，整体流程如下：

- **序数形状分支（OSB）**：
  - 将支持图像的像素到边界距离（EDT）均匀离散为 $K$ 个区间（bins），形成序数层次标签（bin 0 表示边界，$K-1$ 表示质心区域）。
  - 设计一个轻量级解码器，从骨干网络特征预测每个前景像素的 bin 分布。
  - 训练目标包含两项：标准的交叉熵分类损失 $\mathcal{L}_{\text{cls}}$ 和序数距离惩罚 $\mathcal{L}_{\text{dist}}$。后者按预测 bin 与真实 bin 的序数间隔成比例惩罚错误分类，强制几何嵌入随层次单调变化。总损失为 $\mathcal{L}_{\text{OSB}} = \mathcal{L}_{\text{cls}} + \lambda_{\text{dist}} \mathcal{L}_{\text{dist}}$。

- **几何感知原型增强（GAPE）**：
  - 局部原型池化：将支持特征图划分为 $G \times G$ 的空间网格，对每个前景细胞做掩码平均池化得到局部外观原型 $\mathbf{p}^{\text{fg}}_i$。
  - 几何偏移嵌入：利用 OSB 预测的 bin 概率分布，计算每个细胞的平均序数层次 $\bar{d}_i$，再通过一个轻量 MLP 将其映射为 $C$ 维几何偏移向量 $\mathbf{e}_i$。
  - 原型增强：通过加法融合得到增强原型 $\mathbf{p}'_i = \mathbf{p}^{\text{fg}}_i + \mathbf{e}_i$，使特征空间具有显式的几何拓扑，匹配时不仅考虑外观相似性，也考虑结构对应关系。
- **查询分类与正则化**：增强的原型与查询特征进行余弦相似度计算，并通过双向原型对齐正则化（PANet 风格）稳定训练。总损失为 $\mathcal{L} = \mathcal{L}_{\text{CE}}(\hat{M}_q, M_q) + \mathcal{L}_{\text{align}} + \lambda_{\text{geo}}\mathcal{L}_{\text{OSB}}$。

### 8. 不足与局限
- **2D 处理限制**：当前方法在 2D 切片上操作，未利用三维体积的连续性。对于靠近器官边界的切片，EDT 层次可能不稳定，未来可扩展至 3D。
- **固定分箱策略**：采用均匀分箱，对形态不规则或尺寸过小的目标（如皮肤病灶）可能不适配，且 bin 数量 $K$ 需针对器官尺度调节，缺乏自适应性。

- **跨域泛化边界**：模型训练仍依赖源域数据，对于与源域几何差异极大的目标（如表 3 中 ISIC 结果逊于部分方法），几何先验的迁移性存在上限。
