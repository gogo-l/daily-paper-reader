## 摘要
在线持续学习（OCL）旨在从无穷无尽的非平稳数据流中学习，然而现有方法大多假设一个扁平的标签空间，忽略了现实世界概念的分层组织结构，该结构在横向（兄弟类别）和纵向（粗粒度或细粒度类别）上都会演化。为了更好地反映这一背景，我们引入了一个新的问题设定，DHOCL（动态层次结构下的在线持续学习），其中分类体系在不同粒度上演化，每个样本仅在一个层次上提供监督。在此设定下，我们发现了两个根本性问题：（i）混合粒度下的部分监督仅提供演化路径层次上的逐点信号，限制了可塑性并破坏了跨层次语义一致性；（ii）动态演化的层次结构引发了依赖于粒度的干扰，使得常用的回放和正则化机制变得不稳定，从而加剧了灾难性遗忘。为解决这些问题，我们提出了HALO（基于组织化原型的层次自适应学习），它自适应地组合互补的分类头，并通过组织化的可学习层次原型进行正则化，从而在分类体系演化过程中实现快速适应、层次一致性以及结构化知识巩固。在多个基准上的广泛实验表明，HALO在层次准确性、错误严重性和持续学习性能方面始终优于现有方法。

## Abstract
Online Continual Learning (OCL) aims to learn from endless non\text{-}stationary data streams, yet most existing methods assume a flat label space and overlook the hierarchical organization of real\text{-}world concepts that evolves both horizontally (sibling classes) and vertically (coarse or fine categories). To better reflect this context, we introduce a new problem setting, DHOCL (Online Continual Learning from Dynamic Hierarchies), where taxonomies evolve across granularities and each sample provides supervision at a single hierarchical level. In this setting, we find two fundamental issues: (i) partial supervision under mixed granularities provides only point-wise signals over an evolving path-wise hierarchy, which constrains plasticity and undermines cross-level semantic consistency, and (ii) the dynamically evolving hierarchies induce granularity-dependent interference, destabilizing popular replay and regularization mechanisms and thereby exacerbating catastrophic forgetting. To tackle these issues, we propose HALO (Hierarchical Adaptive Learning with Organized Prototypes), which adaptively combines complementary classification heads, regularized by organized learnable hierarchical prototypes, enabling rapid adaptation, hierarchical consistency, and structured knowledge consolidation as the taxonomy evolves. Extensive experiments on multiple benchmarks demonstrate that HALO consistently outperforms existing methods across hierarchical accuracy, mistake severity, and continual performance.

# 论文深度分析报告：《Online Continual Learning with Dynamic Label Hierarchies》

## 1. 核心问题与整体含义（研究动机和背景）
本研究聚焦于**在线持续学习（Online Continual Learning, OCL）**在面对现实世界动态、分层的知识结构时所暴露的局限性。

*   **核心问题**：
    *   **现有OCL方法的“扁平”假设**：当前主流的OCL方法通常假设一个“扁平”的标签空间，即所有类别彼此独立且语义等距。这与现实世界中概念的自然分层组织（如生物学分类：界-门-纲-目-科-属-种）严重脱节。
    *   **忽视层次结构的动态演化**：现实世界中的分类体系（Taxonomy）并非一成不变。它不仅会**横向扩张**（发现新物种/类别），还会**纵向细化或抽象化**（新增/修订中间层级）。例如，一个鸟类观察者可能先看到一只具体的“黑翅王鹟”，随后才遇到并学习其更粗粒度的上级分类“鸟类”。现有OCL方法无法处理这种标签随时可能以任意粒度、任意顺序到达的复杂情况。

*   **整体含义**：本文旨在填补OCL研究中的一个关键空白，即**如何在一个标签结构本身随时间动态演化、且样本标注粒度混合的环境中进行有效的持续学习**。作者正式定义了一个更具挑战性也更贴近现实的新问题设定——**DHOCL（动态层次结构下的在线持续学习）**。

## 2. 论文提出的方法论（HALO框架）
为解决DHOCL中因**部分监督、结构解耦**和**粒度依赖性干扰**带来的挑战，作者提出了**HALO（Hierarchical Adaptive Learning with Organized Prototypes）**框架。其核心思想是通过两个互补的模块来协调学习的可塑性与稳定性。

*   **核心思想**：
    *   **层次原型正则化（HPR）**：在特征空间中引入可学习的层次原型（Prototypes），作为“拓扑胶水”来强制执行特征表示与演化中的分类树之间的对齐，确保跨层次语义一致性。
    *   **自适应预测聚合（PredLA）**：在预测层面动态组合两种特性互补的分类器，以平衡对新兴概念的快速适应（可塑性）与对旧知识的稳定保持（稳定性）。

*   **关键技术细节与流程**：
    *   **双层分类器架构（PredLA的核心）**：
        1.  **可训练的线性分类头 (`$g_{lin}$`)**：基于可训练的特征提取器 `$f(x)$` 进行端到端优化，以最大化适应性，擅长处理新任务和粗粒度分类。
        2.  **解析（冻结的）分类头 (`$g_{acil}$`)**：基于一个**冻结**的预训练骨干网络 `$f_0(x)$` 的特征，通过递归最小二乘法（RLS）更新权重。它牺牲了可塑性，但提供了极强的稳定性，能有效抵抗对旧类别（尤其是细粒度类别）的灾难性遗忘。
        *   **聚合机制**：在预测阶段，对两个分类头的输出（`$p_{lin}$` 和 `$p_{acil}$`）进行温度缩放和加权求和（`$\hat{p} = \alpha p_{lin} + (1-\alpha) p_{acil}$`）。关键的权重 `$\alpha$` 和温度 `$\tau$` 并非在流数据上学习，而是在回放缓冲区（Memory Buffer）的数据上进行双层优化，从而解耦了聚合学习与短期数据分布漂移。
    *   **层次原型正则化（HPR）**：
        1.  **原型构建**：通过一个轻量级适配器 `$f_A$`，将骨干网络特征映射到一个原型空间。为层次树中的每个节点（类别）学习一组可训练的局部原型 `$\mathbf{P}^h_c$`。分类时，计算输入特征块与原型间的最大余弦相似度来产生logits。
        2.  **双重正则化**：
            *   **层次结构对齐**：通过一个基于排序的损失函数，在特征空间中拉近祖先-后代原型对的距离，同时推远其与树外无关原型对的距离，从而将分层拓扑结构“烘焙”进表示空间。
            *   **时间显著性一致性**：约束模型对历史缓存原型与新特征之间在关键空间位置（Top-K相似度区域）的相似度变化，为粗粒度语义提供稳定性，同时不损害对新细粒度特征的塑性。

## 3. 实验设计
*   **使用的数据集/场景**：
    1.  **CIFAR-100**：图像尺寸32x32，3层平衡层次结构（超类/类/子类）。
    2.  **FGVC-Aircraft**：图像尺寸224x224，3层近似平衡层次结构（家族/变体/子变体）。
    3.  **CUB-200-2011**：图像尺寸224x224，3层近似平衡层次结构（目/科/种）。
    4.  **iNaturalist-2018**：图像尺寸224x224，7层深度平衡层次结构（从界到种），但类别数据量极度不平衡。
    5.  **ImageNet-H**：图像尺寸224x224，基于WordNet的非平衡层次结构，树深不一。

*   **DHOCL基准（Benchmark）构建**：
    *   将数据集的细粒度类别划分为若干连续组，并通过类别重叠模糊组间边界，模拟无明确任务边界的持续数据流。
    *   每个样本仅在一个随机的层次粒度上提供标签，模拟现实世界中不完整、多粒度的监督信号。
    *   数据流处理遵循单遍（single-pass）训练协议，对样本不足的数据集进行有限次的增强重复。
